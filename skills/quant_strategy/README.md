# 量化策略类

> 组件层 · 量化策略类

本目录承载**量化策略信号**相关的 Skill：从量化策略数据库筛选策略、获取策略持仓、
把「策略信号」转化为「标的池」，供上层选股 / 诊股 / 策略场景编排调用。

> 架构说明：本层 Skill 取数直连外部策略数据源（远程 MySQL 策略库等，属「策略信号源」
> 而非行情数据源），**不经 ctx.gateway**（见各 Skill 的 `calls_gateway=false`）。
> 这是与组件层契约「统一走网关」的已知缺口，待后续统一改造。
