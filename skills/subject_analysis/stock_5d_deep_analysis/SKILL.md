# 股票五维深度分析（单标的 · 五维度框架）

## 一、技能定位

本技能把 racing-quant-ai 的「5 维度个股深度分析框架」落地为 **单只股票深度分析** 场景：对一只 A 股标的独立完成五维度分析，输出结构化深度研究报告。五维度框架是底层引擎，同业/行业对标作为 **可选增强**，把绝对结论放到相对坐标系里校验。

> 适用：个股深度诊断、买方/卖方初筛、回答"这只票到底怎么样"、在深度分析基础上顺带看相对同业的贵贱强弱。

## 二、五维度个股分析框架（核心）

完整字段与取数口径见 `references/analysis-framework.md`。五维度概要：

| 维度 | 内容 | 关键产出 |
|---|---|---|
| ① 核心交易数据 | 现价、涨跌幅、日内区间、量额、换手、总市值、PE(TTM)/PB | 估值与交易状态快照 |
| ② 股价走势回顾 | 近5日/1月（短）、近3月（中）、近1年/5年（长）涨跌幅 | 多周期动量 |
| ③ 资金面 | 主力净流入/出、主力成本 vs 现价、机构控盘度、支撑/压力位 | 资金态度 |
| ④ 基本面核心 | 估值 vs 行业均值、营收/净利增速与稳定性、业务亮点、风险 | 质地与估值 |
| ⑤ 综合评价 | 短/长期判断、保守/稳健/激进投资者建议、免责声明 | 结论 |

## 三、同业/行业对标层（可选增强）

当用户要求"和同行比 / 相对同业"时，**叠加**以下相对逻辑（非必须）：

1. **确定可比集合**：优先用户指定；否则按申万二级/三级行业取可比公司（剔除 ST、上市不足一年、数据缺失标的）。
2. **相对估值**：目标 PE/PB vs 同业中位数/均值 → 溢价(+)/折价(-) 及同业分位。
3. **相对动量**：目标近1月/1年涨幅 vs 同业均值。
4. **相对基本面**：ROE、营收/净利增速 vs 同业分位。
5. **相对资金**：主力净流入强度 vs 同业。
6. **同业排名**：综合打分在同业中的百分位。

## 四、数据来源与降级（铁律）

- 优先级：**Tushare（优先） → akshare → 东方财富/腾讯兜底**。每本报告必须标注实际使用的数据源与具体接口。
- 所有行情/财务/资金数据必须来自实际调用结果；取数失败如实标注 **"数据获取失败"**，**严禁编造任何具体数值**（见 `references/analysis-framework.md` 数据校验铁律）。

## 五、输出格式

严格按 `references/output-template.md` 输出：核心摘要 → 五维度逐维分析 →（可选）同业对标 → 综合评价与风险提示 → 信息来源 → 免责声明。报告同时保存为 Markdown 与 HTML 至 `reports/` 目录。

## 六、工具调用规范

1. 优先用 Tushare（`daily` / `daily_basic` / `fina_indicator` / `moneyflow`）取行情、估值、财务、资金；不可用时降级 akshare；再不可用时东方财富/腾讯兜底。
2. 基本面/事件补充用 `cn-web-search` / `WebSearch` 检索公开研报与公告，引用须标注来源。
3. 每维度数值须与数据源原始口径交叉校验，异常极值单独高亮备注。
