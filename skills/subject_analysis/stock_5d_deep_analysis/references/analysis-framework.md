# 五维度个股分析框架（股票五维深度分析 · 引擎规格）

> 本文件是 `stock_5d_deep_analysis` 的分析引擎定义，供 SKILL.md 引用。对单只标的执行以下五个维度，
> 所有数值必须来自实际数据源调用，禁止估算或编造。同业/行业对标为**可选增强**，口径见文末。

## 维度 1 · 核心交易数据

| 字段 | 说明 | 优先级数据源 |
|---|---|---|
| 最新价 / 当日涨跌幅 | 当前交易状态 | Tushare `daily` / `daily_basic` → akshare `stock_zh_a_spot_em` → 东财 Push API |
| 日内区间（最高/最低） | 波动区间 | 同上 |
| 成交量 / 成交额 / 换手率 | 活跃度 | Tushare `daily_basic` → akshare |
| 总市值 | 规模 | Tushare `daily_basic` → akshare |
| 估值 PE(TTM) / PB | 估值水平 | Tushare `daily_basic` → akshare |

**校验**：量价、市值、PE/PB 必须与调用源实时核对；异常空值/离谱极值高亮备注。

## 维度 2 · 股价走势回顾

| 周期 | 口径 |
|---|---|
| 短期 | 近 5 日、近 1 个月涨跌幅 |
| 中期 | 近 3 个月涨跌幅 |
| 长期 | 近 1 年、近 5 年涨跌幅 |

**校验**：多周期涨跌幅须匹配数据源原始口径核验计算逻辑，杜绝偏差（注意 Tushare 复权参数）。

## 维度 3 · 资金面

- 近期主力资金净流入 / 净流出（逐日）
- 主力持仓成本 vs 当前股价（盈利/套牢区）
- 机构控盘度（筹码集中度）
- 关键支撑位 / 压力位

**校验**：主力资金流向明细严格校验数据源原始流水；异常波动单独标注。

## 维度 4 · 基本面核心

- 估值对比：当前 PE/PB 对比行业平均，判断高估 / 低估
- 业绩表现：近期营收、净利润增速与增长稳定性
- 业务亮点：核心优势、新增长点
- 风险提示：高负债、政策风险、行业周期等（客观列出）

**校验**：营收、净利润、ROE 等核心指标必须对照数据源原始财报字段精准校验，保证可溯源。

## 维度 5 · 综合评价

- 短期趋势判断（资金面 + 技术面）
- 长期投资价值评价（基本面 + 估值）
- 不同类型投资者参考建议（保守 / 稳健 / 激进）
- **必须添加免责声明**：本服务内容来源于公开及第三方数据源，仅自动化加工展示，不构成投资建议或承诺，不能替代独立判断。受数据源、传输、解析等因素影响，内容可能存在偏差，不保证内容真实准确完整。服务方不对据此决策产生的后果负责。市场有风险，投资需谨慎。
- **必须标注**：本次行情/财务/资金数据的实际来源

## （可选）同业/行业对标 · 相对指标口径

仅当用户要求"和同行比 / 相对同业"时计算，用于把绝对结论放到相对坐标系校验：

| 相对指标 | 计算 | 解读 |
|---|---|---|
| 相对估值 | 目标 PE/PB ÷ 同业中位数 → 溢价(+)/折价(-)；并取同业分位 | 贵/便宜 |
| 相对动量 | 目标近1月/1年涨幅 − 同业均值 | 强/弱于同业 |
| 相对基本面 | 目标 ROE / 营收增速 的同业分位（如前 20%） | 质地优劣 |
| 相对资金 | 目标主力净流入强度 − 同业均值 | 资金偏好 |
| 同业排名 | 综合打分在同业中的百分位 | 综合位置 |

**可比集合规则**：优先用户指定；否则按申万二级/三级行业取，剔除 ST、上市不足一年、数据缺失标的。

## 数据校验铁律（重大事故防线）

> 源自 racing-quant-ai 2026-07 数据幻觉事故修复，纳入为通用护栏。

1. **严禁编造**：任何分析报告中，行情/财务/资金数据只能来自实际调用结果。
2. **失败如实标注**：数据获取失败必须标注 **"数据获取失败"**，不得用估算值、猜测值或模型生成值替代。
3. **可溯源**：报告中每个数值必须可溯源至具体数据源调用（接口名 + 时间）。
4. **降级留痕**：每次取数记录实际命中的数据源（Tushare / akshare / 东财 / 腾讯），并在报告末尾标注。
5. **交叉校验**：多源可用时，对关键字段（最新价、PE）做跨源交叉验证，不一致时高亮说明。
