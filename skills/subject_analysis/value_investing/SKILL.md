# 价值投资skill — 自上而下基本面价值选股框架

> 方法论来源：用户提供的基本面分析专家提示词（`stock-fundamental-analysis-expert` v1.0），2026-11-17 固化为可执行 skill。
> 五步框架：**宏观 → 行业 → 公司质量(SWOT) → 估值 → 综合结论与风险**。
> 两条不可动摇的信条：**好公司 ≠ 好股票**、**价值 ≠ 价格**。
> 本 skill 不是荐股工具，只提供分析框架与参考结论；所有输出不构成投资建议。

## 一、何时使用 / 何时不用

**触发（用本 skill）**
- 给出公司名称、股票代码或行业名称，要求做基本面分析、价值投资辅助、选股决策支持。
- 问「现在这个价格贵不贵 / 能不能买 / 值不值得关注」「买什么」。
- 多只股票的价值横向对比、行业前景比较、定期报告与财务数据解读。
- 要求把「好公司」与「好价格」分开评估，或复盘价格与内在价值的偏离。

**不触发（转其它 skill）**
- 买卖时机、技术形态、回测择时 → `技术择时分析` / `游资技术择时分析` / `波段股价计算`（技术面只作短期互补，不替代本框架）。
- 只要 PE/PB/历史分位/DCF 的精细估值 → `四步估值模型`（本 skill 的 Step 4 可直接引用其结果）。
- EPS 增长 × PE 扩张的成长股双击测算 → `戴维斯双击选股skill`。
- 筹码分布、资金流、情绪因子、量化因子 → 对应专用 skill。

**联动约定**：Step 4 需要 PE-TTM、历史分位、行业基准、DCF 内在价值时，优先调用 `四步估值模型` 或按 `references/data-sources.md` 自行取数；引用时必须保留其数据日期与口径，禁止混用不同口径的 PE。

## 二、输入与前置

- 标的：公司名称 / 6 位代码（多只用逗号分隔）/ 行业名称；A 股为主，港股、美股需显式标注口径差异。
- 可选项：报告基准日、持有周期、同行对比清单、输出形式（对话表格 / CSV / HTML）、估值模型偏好。
- **禁止凭记忆填数**：所有财务与行情数字必须来自数据源或用户给定材料，并标注数据日期与来源。
- 缺少关键数据时，执行 Step 0 后显式列出「数据缺口清单」，并在结论中降级表述，不得静默补全。

## 三、工作流程（严格按序，每步独立成章）

### Step 0｜取数与口径校验（本 skill 增加的可执行层）
1. 按 `references/data-sources.md` 的数据源声明选源：按 `level` 由小到大、命中即止；工具未配置/超时/返回空即降级，四级全失败则明确列出数据缺口，**不得用记忆值兜底**。凭据由使用者自助配置，本 skill 不内置任何地址、账号或密码。
2. 关键数字（现价、PE-TTM、PB、归母净利、营收、ROE、经营现金流、总股本）至少两源交叉验证；**估算值与权威源冲突时，以权威源重做该步骤分析**。
3. 单位与口径自检：股本单位（万股 / 股）、PE-TTM 与静态/动态 PE、TTM 与年报口径、归母与扣非、复权价格；任何比值型指标先核单位再计算。
4. 缺失值保留为空（N/A），**「未知」不等于「数值为零」**；不得把缺失项填 0 参与评分或结论。
5. 产出：`数据表`（含来源、日期、口径）+ `数据缺口清单`，供后续步骤引用。

### Step 1｜宏观经济基本面分析
从四个方向评估对标的的影响，输出「利好 / 中性 / 不利」+ 核心依据：
1. **国际形势**：主要国家政策导向、地缘冲突、战争风险 → 全球风险溢价变化。
2. **宏观指标**：GDP 增速、通胀/通缩、经济周期位置、指标公布时间与拐点信号。
3. **财政政策**：税收、支出、国债、补贴、转移支付；减税降费 / 基建扩张 / 行业区域扶持 → 就业、收入、证券市场传导。
4. **货币政策**：法定存款准备金率、存贷款利率、公开市场操作、贴现政策；降准降息属全面放松并带来增量资金，公开市场操作与贴现属阶段性定向调节；跟踪货币供应量、市场利率与资金面。

### Step 2｜行业基本面分析
1. **经济周期匹配**：顺周期（银行、基建、钢铁、汽车）/ 逆周期（口红经济：化妆品、电影）/ 刚需防御（食品饮料、医疗保健、公用事业）。
2. **波特五力**：行业内竞争、潜在进入者、替代品、供应商议价能力、购买者议价能力；结合经济好 / 一般 / 差三种情景预测行业变化。
3. **生命周期**：初创期 → 成长期 → 成熟期 → 衰退期。
输出：行业阶段、核心驱动力、主要风险点、是否具备长期增长前景、适合的投资风格（保守型 / 进取型）。

### Step 3｜公司质量分析（SWOT）
按优势 Strengths / 劣势 Weaknesses / 机会 Opportunities / 威胁 Threats 四象限逐项给证据，并回答三问：
- 是否为行业中最能分到增长蛋糕的龙头或优质企业？
- 相对竞争对手是否存在显著且可验证的优势（市占率、定价权、成本、研发、渠道）？
- 发展前景是否看好？依据是什么？
定性判断必须附可核验事实（财报科目、公告、行业数据），禁止空泛形容词堆砌。

### Step 4｜公司估值分析
**按公司类型选指标**（详见 `references/methodology.md`）：
| 指标 | 公式 | 适用类型 |
|---|---|---|
| PE 市盈率 | 股价 / 每股收益 | 盈利稳定型 |
| PB 市净率 | 股价 / 每股净资产 | 资产重型、重资产 |
| PEG | PE / 净利润增长率 | 高成长型 |
| PS 市销率 | 市值 / 上年度营业收入 | 营收高但利润低 |

**模型选择**：DCF（商业模式简单、净利润≈自由现金流，如白酒）、FCFF、CAPM（贴现率）、股息贴现（高分红型）；写明假设参数与适用前提，给**区间**而非单点。
**判断**：当前价格处于高估 / 合理 / 低估哪个区间；与自身历史（近 3 年分位）、与同行中位数双向对比；明确估值不确定性（增速假设、周期位置、一次性损益、商誉、会计政策）。
**必守**：价值 ≠ 价格，价格围绕内在价值波动；亏损或 PE 失真时切换 PB / PS 视角，不得强行套 PE。

### Step 5｜综合结论与风险提示
用简洁语言回答三件事：① 值不值得关注（买什么）② 当前价格能不能买（能不能买）③ 需要重点跟踪的基本面信号。
**必须包含风险提示章节**，逐条覆盖 `references/methodology.md` 的六条清单（信息滞后、财务造假、估值主观性、技术面互补、基本面优势、基本面劣势），并以「结论仅供参考，不构成投资建议」收尾。

## 四、可选量化层：四层打分卡

用于多股横向对比或需要可复现排序时；单只定性分析可跳过。计算由 `scripts/value_scorecard.py` 完成（纯标准库、离线可跑）。

| 层级 | 权重 | 分数来源 |
|---|---|---|
| 宏观 | 15% | Step 1 结论映射，人工给分并附依据 |
| 行业 | 25% | Step 2 结论映射，人工给分并附依据 |
| 公司质量 | 30% | Step 3 SWOT 结论映射，人工给分并附依据 |
| 估值 | 30% | 脚本按 PE 历史分位 35% / 相对同行 PE 25% / 相对同行 PB 15% / PEG 15% / DCF 安全边际 10% 计算 |

**评分锚点（三层定性分）**：80–100 多项证据明确向好且龙头地位可验证；60–79 偏正面但有 1–2 项未验证；40–59 中性或多空交织；20–39 偏负面；0–19 明确恶化。每层至少写 2 条可核验依据，**无依据则该层记 N/A、不打分**。

**硬规则**
- 估值权重不低于任何单一层级，体现「好公司≠好股票」；估值层数据不足时**禁止输出总分与「能不能买」的结论**，只保留质量层评价。
- 缺失项按剩余权重比例分摊并标注「权重已重分配」，**绝不填 0**；缺失 ≥2 层时不输出总分。
- 分数是框架辅助，**不得据分数直接下买入/卖出结论**；最终表述用「值得关注 / 需等待更合理价格 / 估值偏贵 / 观察 / 数据不足」。
- 禁用语：推荐、买入、卖出、目标价、必涨、稳赚。

**用法**
```bash
python3 {SKILL_DIR}/scripts/value_scorecard.py --example          # 查看输入 JSON 契约
python3 {SKILL_DIR}/scripts/value_scorecard.py --input data.json --out report.csv
python3 {SKILL_DIR}/scripts/value_scorecard.py --selftest         # 校验缺失值/口径规则
```
脚本输出 Markdown 表格（对话内展示）+ UTF-8 BOM 的 CSV（Excel 直接打开）+ 数据缺口清单。

## 五、输出格式（硬约束）
1. **先结论后证据**：开头 100–200 字给「值不值得关注 / 当前能不能买 / 关键理由」，再展开五步拆解。
2. 每个步骤独立成章、结论明确，标题层级清晰，结构化分点。
3. 表格化呈现具体数字，逐项标注数据日期、来源与口径；专业但不晦涩，适当用类比与举例。
4. 强调「好公司 ≠ 好股票」「价值 ≠ 价格」，把公司质量与价格判断分开写。
5. 必含「估值不确定性」与「数据缺口」段，多股对比另附横向表与 CSV。
6. 必含**风险提示章节**与免责声明；不推荐股票、只给分析框架与参考结论。
7. 输出 HTML 时遵循 A 股惯例：涨用红色、跌用绿色；货币符号用 ¥。

## 六、铁律（违反即输出无效）
- 不荐股、不给目标价、不说买卖指令；结论仅供参考，不构成投资建议。
- 不凭记忆造数；关键数字至少两源交叉，与权威源冲突时以权威源重做。
- 「未知」≠「0」：缺失保留 N/A 并降级结论，禁止静默填 0；单位先核再算。
- 诚实披露否定结果与模型局限：估值主观、模型差异大、财务信息可能失真，不调参掩盖不利结论。
- 基本面解决长期方向、无需盯盘、利于心态；但信息滞后、财务可靠性存疑、估值困难，必须与风险提示一起呈现。
- 技术面可作互补（解决短期时机），不得用技术信号反推基本面结论。
