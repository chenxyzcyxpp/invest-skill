## 八、风险提示（必须完整）

1. **信息滞后性**：基本面数据披露有周期，普通投资者信息渠道单一，结论可能落后于经营变化。
2. **财务造假风险**：安然事件、獐子岛事件表明财报可能失真，需具备财务辨别能力（关注现金流、应收、存货、关联交易）。
3. **估值主观性**：不同模型、不同假设结果差异大，本报告给区间而非单点。
4. **技术面互补**：技术面解决短期买卖时机，基本面解决长期方向；本框架不替代择时。
5. **基本面分析优势**：判断长期运行方向、无需时刻盯盘、有利于心态稳定。
6. **基本面分析劣势**：信息滞后、财务可靠性存疑、估值困难。
