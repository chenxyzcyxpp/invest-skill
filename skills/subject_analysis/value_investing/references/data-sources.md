# 数据源声明、取数规范与字段口径

> **用途**：支撑 `SKILL.md` 的 Step 0（取数与口径校验）。所有数字必须带「来源 + 数据日期 + 口径」。
> **契约**：本文件遵循 invest-skill《数据网关参考规范》(`skills/base/GATEWAY_REFERENCE.md`) 的降级链、
> 字段交叉校验与防幻觉护栏；本 skill 为提示词驱动型（`llm_prompt`），数据层由 Agent 经**使用者环境中已配置的工具**承担，
> 故 `calls_gateway: false`（不经统一网关，非「不取数」）。
> **红线**：凭据零硬编码、缺失如实标注、禁止编造；连接状态随会话变化，执行前以当前可用工具为准，
> 任一路径失败按第 2 节降级链切换，**不得用记忆值兜底**。

## 1. 数据源声明（结构化）

> 字段语义对齐 `manifest.yaml` 的 `data_sources`：`level` 优先级 / `name` 名称 /
> `role` 角色 / `requires` 依赖（环境变量或已配置工具）/ `coverage` 覆盖范围。
> `requires` 只描述「需要什么」，不含任何地址、账号、密码或本机绝对路径；凭据由使用者自助配置并合规授权。

| level | name | role | requires | coverage |
|---|---|---|---|---|
| 1 | 东方财富妙想 MCP (`mx-ds-mcp`) | 财务 / 宏观 / 新闻研报主源 | 使用者已配置的 `mx-ds-mcp` | A 股财务、宏观指标、板块指数、公告与新闻检索、条件选股 |
| 1 | 通达信 MCP (`tdx-connector`) | 行情 / 身份核对主源 | 使用者已配置的 `tdx-connector` | 实时行情、K 线、个股深度资料、技术指标、研报问答；代码/名称映射较可靠，优先用它确认标的身份 |
| 2 | 四步估值模型 skill | 精细估值 | 使用者环境中存在该 skill | PE-TTM 历史分位、行业自适应基准、DCF 情景区间、52 周区间；Step 4 直接引用其结果并保留数据日期 |
| 2 | 东方财富网页源（push2 / push2his） | 网页兜底 | 可联网（WebFetch / curl 任一可用） | 实时快照与 260 日 K 线；命令行不可达时优先网页抓取 |
| 3 | 巨潮资讯 / 交易所公告 / 定期报告 / 财联社 | 权威校验源 | 公开可访问 | 财报原文、业绩预告、重大事项；算法估算与官方数据冲突时**以官方重做分析** |
| 4 | Tushare（可选增强） | 结构化补充源 | 使用者配置 `TUSHARE_TOKEN` 环境变量 | 一致预期、行业分类、历史行情；仅在前述源不足且 token 可用时启用 |
| 4 | Wind / 中国银河 AmazingData（可选增强） | 结构化补充源 | 使用者自有终端与授权（自担合规） | 精确估值、行业指数与成分股、融资融券、龙虎榜、股东户数；见第 7 节环境相关踩坑 |

**交叉验证规则**：现价、PE-TTM、PB、归母净利、营收、ROE、经营性现金流、总股本这 8 项，至少两源一致或经官方公告确认；
存在差异时列出「源 A / 源 B / 采信值 + 理由」，偏差超阈值（价格类 > 1%、比率类 > 5%）标记 `conflict` 并显式提示歧义，
不自动选用其一掩盖差异。行业分类统一用申万一级（冷门三级行业指数更新滞后会导致日期错位）。

## 2. 降级链与执行规则

按 `level` 由小到大尝试，**命中即止**；上级不可用（工具未配置 / 超时 / 返回空 / 关键字段缺失）才降级到下级。
四级全失败 → 明确报错并列出数据缺口，**禁止**返回「看起来合理」的占位值、过期缓存或模型编造值。

1. **顺序不跳级**：同级内可任选可用源，跨级须按 `1 → 2 → 3 → 4`。
2. **统一失败判定**：工具未配置、超时、异常、返回空、关键字段缺失率超阈值，均触发降级。
3. **命中即止**：取到满足口径的数据后立即停止尝试更低级源。
4. **全失败明确报错**：输出 `数据缺失 / N/A` 并说明对结论的影响，不静默补全（见第 3 节护栏）。
5. **降级留痕**：报告中记录实际采信来源与切换路径（哪级不可用、因何切换、最终采信），供复盘与审计。
6. **局部失败不阻断**：某一维度取数失败，仅该维度标记「暂无法获取」，其余维度正常输出，整体报告照常生成但不掩盖缺失。

## 3. 防幻觉护栏（最高优先级红线）

> **铁律**：数据不可用必须如实标注缺失，严禁编造、估算、插值、脑补任何数值或事实。

1. **不编造**：取数失败或字段缺失，一律标注 `数据缺失 / N/A / 源不可用`；绝不由模型生成数字、结论或引用。
2. **可溯源**：每个数字标注来源与数据日期；读者必须能区分「实测数据」与「本报告观点 / 推演」。
3. **降级留痕**：记录完整切换轨迹与最终采信来源（见第 2.5 条）。
4. **明确报错**：全源失败返回错误与缺口清单，不降级到过期缓存或占位值。
5. **事实与结论分离**：模型推断（如「预计向好」「估值偏贵」）须与事实数据分离标注，不把推断当已验证事实。
6. **未知 ≠ 0**：比值型指标缺失保留 N/A，不填 0 参与评分或结论（填 0 会造出量纲上不可能的离群值）。

## 4. 字段口径红线

- **PE-TTM 必须取东财 `f164`**；`f162` = 市盈率(动)、`f163` = 市盈率(静)。误用 `f162` 会把估值系统性算低（实测某标的 106.85x 被错算成 74.93x）。
- `f43` 现价 ÷100、`f167` PB ÷100、`f116` 总市值(元)、`f117` 流通市值(元)、`f171` 当日涨跌幅 ÷100 → %（**不是 YTD**）。
- `f55` / `f60` 经常异常，**52 周高低一律用 260 日 K 线的真实 high/low**（klines 每行「日期,开,收,高,低,量」，索引 3 / 4，不再 ÷100）。
- 历史分位：取 ≥260 个收盘价排序，`pct = (≤现价的个数 / n) × 100`；价格分位 ≠ 估值分位，戳破「跌了就便宜」陷阱。
- YTD：用当年第一根 K 线收盘价与现价比较，勿用 `f171` 代替。
- 代码统一带市场前缀（如 `sh600519` / `sz000858`）；跨源取数前先核对证券代码与简称，防止张冠李戴。
- 财务口径：区分 TTM 与年报、归母与扣非、并表范围变化、一次性损益、商誉减值、经营性现金流与净利润背离。
- 估值模型参数（r、永续 g、显式高增期、增速情景）必须写明，且给区间不给单点。

## 5. 单位与量纲自检（每次计算前执行）

1. **股本单位**：银河 `get_equity_structure` 的 `TOT_TRADABLE_SHARE` 是**万股**，K 线 `volume` 是**股**。换手率 = `volume / (股本_万股 × 1e4) × 100`。误按「股」算会出现 3.4 万倍荒谬值。
2. 市值：元 / 万元 / 亿元统一后再做 PS、PB。
3. 百分比：增长率 15% 记为 15 还是 0.15，PEG 计算前统一（脚本契约见 `scripts/value_scorecard.py`，PEG 输入为倍数）。
4. 比值型特征缺失时保留 N/A，**不得填 0**（同第 3.6 条）。
5. 流通股本按 `CHANGE_DATE` 分段匹配，禁止用当前股本回溯历史。

## 6. 环境相关踩坑（可选增强源，勿重复）

> 以下为跨项目实测经验，仅在使用对应工具时参考；工具不可用时按第 2 节降级，不构成必需依赖。

**银河 AmazingData**：
1. `is_local` 语义反直觉：首次须 `is_local=False` 才从服务端下载；先试 `True` 走缓存，为空回落 `False`。
2. ⚠️ 对未下载过的标的，`is_local=True` 返回**长度为 0 的空 DataFrame**（非 None、不报错），`if df is None` 拦不住 → 特征整列静默变 0。**先 `False` 再 `True`**。
3. 返回类型不统一：`query_kline` 返回 `dict{code: DataFrame}`，`get_industry_base_info` / `get_equity_structure` 直接返回 DataFrame → 统一 `_unwrap()` 兼容。
4. `query_snapshot` 返回 None，换手率改用「成交量 / 流通股本」估算。
5. 限制单点登录 → `MarketData` / `InfoData` 用模块级单例缓存。
6. `InfoData` 连续多次调用后会话偶发静默失效 → 取数加重登录重试 + 进程内缓存。
7. 日志会打印大段 `logon json`，调试输出需过滤，否则淹没真实结果。
8. 行业指数取 **LEVEL_TYPE 一级行业优先**，冷门三级行业指数更新滞后导致日期错位。

## 7. 静默降级排查顺序（一度把结论带偏的教训）

- 任何「分数异常高 / 异常整齐 / 全胜」的结果，先确认各输入列**真的有变异**，检查是否整列被静默置 0 或常数。
- 评分前逐列打印有效值数量与缺失清单；缺失项参与权重分摊而非当作 0 分。
- 结论为负（如「估值不占优」「模型不奏效」）时如实写入，不通过调参掩盖；同时注明样本量 / 数据覆盖范围。
- 合成数据或单一市场的验证结论不可外推到其它行业 / 市场。

## 9. 凭据与合规

- 本 skill 与仓库**不内置任何数据库地址、账号或密码**；第 1 节 `requires` 只声明依赖形态。
- 涉及外部数据源 / 策略库时，由使用者通过环境变量（如 `TUSHARE_TOKEN`）或自有终端自行配置，并自行确保合规授权。
- 禁止在本文件及任何产出中写入本机绝对路径、真实凭据或可反推凭据的片段。
