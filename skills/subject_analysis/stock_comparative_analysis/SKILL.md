# 【股票对比分析报告生成】

基于公开可得数据源（AkShare 开源库 + 交易所/巨潮资讯网/权威财经媒体），为 2-5 只股票（含A股及A+H混合）生成专业对比分析报告。报告包含公司简介、基本面、技术面、资金面、消息面五大章节，输出 Markdown 源文件 + HTML 渲染报告（可选 PDF），所有数据可溯源。

## 功能范围

- **公司简介对比**：股票代码、主营业务、所属行业、概念板块等基本信息
- **基本面对比**：盈利能力、营收增长、净利润、ROE、估值水平（PE/PB/PEG 等）
- **技术面对比**：历史走势、区间涨跌幅、RSI、MACD、KDJ、BOLL 等技术指标
- **资金面对比**：主力资金流向、超大单/大单/中单/小单博弈、融资融券余额
- **消息面对比**：机构研报评级、重大公告、新闻舆情分析
- **综合评述**：五大维度整合总结，观点鲜明的投资参考框架

## 数据源说明

本技能使用两类公开可得数据源，无需任何商业数据库或 API Key：

| 类别 | 数据源 | 获取方式 |
|------|--------|---------|
| 量化行情/财务 | **AkShare 开源库**（聚合东方财富、新浪财经、巨潮资讯网等公开接口） | Python `import akshare` |
| 公告/研报/舆情/政策 | **公开网站**：巨潮资讯网、上交所/深交所、东方财富、政府网、权威财经媒体 | `WebSearch` + `WebFetch` |

**容错降级策略（强制）**：
1. 优先尝试 AkShare 获取量化数据；若 AkShare 未安装或某接口失效，降级为 `WebFetch` 抓取东方财富/新浪公开行情页。
2. 公告、研报、舆情、政策类数据始终通过 `WebSearch` + `WebFetch` 获取。
3. 所有降级获取的数据须在来源角标中注明实际来源与访问时间。

## 数据质量控制规范

### 报告期统一规则（强制）

**核心原则**：所有对比股票必须使用同一报告期进行财务数据对比，取"最滞后"标的的报告期作为基准。

**判定流程**：

1. 数据获取后，分别检查每只股票的最新财务数据报告期
2. 选择所有标的中最晚的报告期作为统一基准（如股票A最新为2025Q3，股票B最新为2025Q2，统一取2025Q2）
3. 所有股票的基本面数据均取该统一报告期的值

**A股+港股混合场景**：

- 港股仅披露半年报和年报，无季报（Q1/Q3）
- 混合对比时，优先使用年报作为统一口径
- 若港股最新为年报、A股有季报，统一取年报口径；若港股最新为半年报、A股有季报，取半年报口径
- 对齐后统一使用"最新可获取的共同报告期"

**禁止事项**：

- 禁止在同一张核心对比表中混用不同报告期的数据（如股票A用Q3、股票B用Q2）
- 禁止将Q1或半年报数据混入年报口径的对比表中
- 若某股票在统一报告期无可用数据，须在表格中标注"数据暂缺（该报告期未披露）"，不得回退到更早报告期

**报告期命名规范**：

- 年报：如"2024年报"
- 半年报：如"2025中报"
- 季报：如"2025年一季报"、"2025年三季报"
- 在对比表标题中显式标注统一报告期，如"表2-1 盈利能力指标对比（报告期：2024年报）"

### 港股数据获取与货币处理

**港股财务数据获取**：

- 港股财务/行情数据通过 AkShare 港股接口（如 `stock_hk_hist`、`stock_hk_financial_indicator_em`）或 `WebFetch` 抓取公开财经网站获取
- 港股财报数据以人民币（RMB）为记账本位币，但股价和市值以港元（HKD）计价
- 获取港股数据时标注"港股"以触发正确的数据源路由

**货币处理规则**：

- 财务数据（营收、净利润、资产等）统一标注币种"人民币"
- 市值数据统一标注币种"港元"，与A股市值"人民币"区分
- 所有涉及市值的对比表格中，必须在表头或指标列中显式标注币种，格式为"总市值（亿港元）"或"总市值（亿人民币）"
- **禁止裸比**：禁止在未标注币种的情况下直接对比 A 股与港股市值数值
- 如需要跨币种对比，应在分析文字中说明汇率差异，并给出换算后的可比口径

**折换人民币参考（强制）**：

- 港股实时行情数据中已包含币种字段（HKD），从行情数据中提取当前汇率
- 在市值对比表中，港股标的的市值行下方增加一行"折合人民币（亿元）"，以当前汇率换算
- 换算公式：折合人民币 = 港股市值（亿港元）× 当前汇率
- 在表格下方标注换算汇率（如"按1港元≈0.87元人民币换算"）
- 汇率获取方式：使用市场通行参考汇率，或通过 `WebSearch` 查询近期权威媒体引用的汇率中枢

**示例**：

```
| 指标 | 腾讯控股(00700.HK) | 贵州茅台(600519.SH) |
|------|---------------------|---------------------|
| 总市值（亿港元） | 45,000 | — |
| 折合人民币（亿元） | 39,150 | — |
| 总市值（亿人民币） | — | 22,000 |

注：按1港元≈0.87元人民币换算
```

### 数据来源交叉验证

**成立日期校验**：

- 接口返回的成立日期可能是工商登记日，而非公司实际创立年份
- 获取公司简介后，须核对公司简介文本描述（如公司简介、发展历程字段）中是否有提及"成立于""创立于""前身"等表述
- 若接口日期与简介文本中的创立年份不一致，以简介文本中的描述为准，并在报告中标注"根据公司简介，实际创立于XXXX年"
- 若简介文本中无明确创立年份，以接口返回的成立日期为准

**通用校验原则**：

- 任何单一接口返回的结构化字段，若与同一数据源返回的文本描述存在矛盾，优先以文本描述为准
- 跨数据源不一致时（如公司简介与财务数据对主营业务描述不同），在报告中标注差异并说明引用来源
- 所有校验结果须在数据来源角标中额外标注"已交叉验证"或"以文本描述为准"

## 数据调用规范

**量化数据使用 AkShare（Python）获取，资讯/公告/研报使用 WebSearch + WebFetch 获取。所有数据须标注来源与访问时间。**

### 公司简介数据

```python
# A股公司简介（东财个股信息）
import akshare as ak
df = ak.stock_individual_info_em(symbol="600519")  # 返回股票代码、简称、行业、上市时间等

# 巨潮资讯网公司简介（补充主营/概念）
ak.stock_profile_cninfo(symbol="600519")
```

### 基本面数据

```python
# A股：财务分析指标（营收、净利润、ROE、毛利率等，含报告期）
ak.stock_financial_analysis_indicator(symbol="600519")

# A股：财务摘要（多报告期对比）
ak.stock_financial_abstract(symbol="600519")

# A股：估值指标（PE/PB/股息率，乐咕乐股）
ak.stock_a_indicator_lg(symbol="600519")
```

### 技术面数据

```python
# A股：区间历史行情（用于计算涨跌幅、振幅、换手率）
ak.stock_zh_a_hist(symbol="600519", period="daily", start_date="20240101", end_date="20250101", adjust="qfq")

# 技术指标（RSI/MACD/KDJ/BOLL）由 pandas 基于历史行情自行计算
# 或降级：WebFetch 抓取东方财富/新浪公开行情页
```

## 报告生成流程

详见 `references/report-template.md`，主要步骤:

1. **解析用户输入** - 提取股票简称或代码（2-5 只）
2. **数据获取** - 按顺序获取上述数据（AkShare + WebSearch/WebFetch）
3. **数据处理** - 检查完整性，标注日期，横向对比
4. **报告撰写** - 按模板结构生成
5. **输出生成** - 先写 Markdown 源文件（含溯源脚标+附录），再基于 Markdown 生成 HTML 渲染报告（可选 PDF），保存至桌面

## 分析写作规范

详见 `references/report-template.md`，核心要求:

- **综合评述**: 1 句话概括核心结论，指明行业，提炼优势与风险
- **各章节**: 开头 1 句话总结差异，数据标注日期，避免罗列重在分析
- **数据缺失**: 标注"数据暂缺"，提示截止日期，不强行解读

## 数据溯源格式规范

### 正文中的溯源角标

**溯源角标统一放在每个小节结束的部分（如 1.1 结束的部分），而不是大章节结尾。**

格式示例：

```
数据来源：[1] AkShare stock_individual_info_em 公司简介、[2] 巨潮资讯网 所属行业分类，公开数据源；数据截止 2026-04-27
```

### 文末数据来源归集（免责声明之前）

**在免责声明章节前增加独立的「数据来源」章节，归集所有使用的数据源。**

格式示例：

```markdown
## 数据来源

[1] AkShare stock_individual_info_em 公司简介；数据截止 2026-04-27
[2] 巨潮资讯网 所属行业分类；数据截止 2026-04-27
[3] AkShare stock_financial_analysis_indicator 财务分析；数据截止 2026-03-31
[4] AkShare stock_a_indicator_lg 估值分析；数据截止 2026-04-27
...
```

**注意**：

- 接口名/数据源名在前，中文名称在后
- 每个来源后用分号（；）分隔，附数据截止日期
- 文字不加粗（保持普通文本样式）
- 使用普通文本格式，不使用表格、引用块等特殊标记
- **HTML 的报告文末数据来源格式与 MD 完全一致，均使用列表格式，不使用表格**
