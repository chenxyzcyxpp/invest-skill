# 数据网关参考规范（可降级多源 · 防幻觉护栏）

> **定位**：本文件是 invest-skill「第三层 · 多源可降级数据网关层」的工程化参考规范，供 `BaseSkill` 取数实现与上层 Skill 调用遵循。
> **来源**：融合 `README.md` 既定三级降级框架，并提炼自 `racing-quant-ai`（chenxyzcyxpp / Warwick）的「四级数据源降级链 + 防幻觉护栏」实践经验。
> **目标**：把"降级顺序 + 字段交叉校验 + 失败如实标注 + 可溯源"固化为可复用的取数契约，反哺 `skills/base` 的 `ctx.gateway` 设计。

---

## 1. 范围与定位

- 网关层屏蔽底层数据源差异，对上层提供**统一标准字段 Schema**，上层 Skill 与业务场景不感知具体数据源。
- 与 BaseSkill 契约的关系：
  - 取数：Skill 统一通过 `ctx.gateway.query(...)` 取数，**禁止直连任何原始数据源**。
  - 输出：实际来源经 `SkillResult.data_source` 透传；完整降级轨迹经 `SkillResult.meta["gateway_trace"]` 透传。
- 本规范是**参考文档（reference）**，不是运行时代码；网关客户端实现应依据本节规则落地，并保持字段映射与降级逻辑对上层无感。

---

## 2. 数据源降级链（四级）

严格按优先级从高到低尝试，命中即止。第 3 级 Baostock、第 4 级东财/腾讯为相对 README 三级框架**新增的强化兜底源**。

| 优先级 | 数据源 | 类型 | 适用字段 | 失败判定 | 备注 |
|--------|--------|------|----------|----------|------|
| 1（优先） | **Tushare** | 授权 API，需 `TUSHARE_TOKEN` | 全品类：行情 / 财务 / 宏观 / 资金流 | 无 token / 限频 / 超时 / 返回空 | 无 token 自动向下降级 |
| 2（次级） | **Akshare** | 开源聚合 API，免 token | 行情、财报、板块、资金 | 接口异常 / 返回空 / 限频 | 偶发不稳定，作为主降级 |
| 3（补充） | **Baostock** | 开源 API，免 token | 历史行情、财务基本面（实时行情弱） | 连接失败 / 字段缺失 | 补"无 token 财务兜底"，财务稳、行情有限 |
| 4（兜底） | **东方财富 / 腾讯财经 网页源** | 网页抓取 / Push API | 基础 K 线、实时行情、基础财务 | 抓取失败 / 反爬 / 返回空 | 不做复杂财务；两源并列，任一可用即兜底成功 |

**说明**
- 第 3 级 Baostock 专门用于补强"无 token 场景下的财务数据兜底"，避免财务类字段在无 Tushare 时直接缺失。
- 第 4 级东财与腾讯为**并列兜底**，只要任一源成功即可视为兜底命中，提升末端可用性。
- 全部四级失败 → 进入第 3 节第 4 条"明确报错"路径，绝不静默返回过期缓存或伪造结果。

---

## 3. 降级执行规则

1. **顺序不可跳级**：严格按 `1 → 2 → 3 → 4` 尝试，除非上级被显式标记为不可用（如缺 token）。
2. **统一失败判定**：超时、抛异常、返回空、关键字段缺失率超阈值，均触发向下降级。
3. **命中即止**：命中任一可用源后立即停止尝试更低优先级源。
4. **全失败明确报错**：四级全部失败，返回明确错误（error），**禁止**静默返回过期缓存、占位值或模型编造值。
5. **重试 / 熔断 / 限流内置**：对爬虫类源（东财/腾讯）控制频率，避免触发 IP 封禁。
6. **降级留痕（trace）**：记录完整切换轨迹——从哪级、因何（超时/空/异常）、切到哪级、最终命中来源，写入 `gateway_trace`。

---

## 4. 字段交叉校验（多源一致性）

避免单源污染，关键字段需做跨源比对：

- 对关键数值字段（如收盘价、总股本、PE/PB、涨跌幅），在主源之外**至少再取一个次级源比对**。
- 偏差超阈值（建议：价格类 > 1%、比率类 > 5%）→ 标记 `conflict`，在输出中**显式提示歧义**，不自动选用其一掩盖差异。
- 字段缺失**不插值、不估算填充**，仅标注"该源缺失"，交由上层如实呈现。

---

## 5. 防幻觉护栏（最高优先级红线）

> **铁律**：数据不可用，必须"如实标注缺失"，**严禁编造、估算、插值、脑补**任何数值或事实。本护栏源于一次数据编造导致的重大事故，为不可妥协的硬约束。

1. **不编造**：取数失败、字段缺失、源无数据，一律如实标注（`数据缺失` / `N/A` / `源不可用`）。绝不允许模型自行生成数字、结论或引用 quote。
2. **可溯源**：每个输出字段标注 `data_source` 与获取时间；报告读者必须能区分**"实测数据"**与**"模型推断"**。
3. **降级留痕**：`SkillResult.meta["gateway_trace"]` 记录完整降级路径，便于复盘、审计与数据源失败率告警。
4. **明确报错**：全源失败 → 返回 error，不降级到过期缓存、不返回"看起来合理"的占位值。
5. **事实与结论分离**：模型推断（如"预计向好""估值偏贵"）须与事实数据**分离标注**，不得把推断当作已验证事实陈述。
6. **局部失败不阻断**：某一维度（如资金面）取数失败，该维度显式标记"暂无法获取"，其余维度正常输出，整体报告照常生成但**不掩盖缺失**。

## 6. 与 BaseSkill 契约衔接

```python
# 调用方（Skill 内部）
record = ctx.gateway.query(symbol="600519.SH", fields=["close", "pe_ttm", "turnover"], as_of="2026-10-22")
# record 含：data（统一 Schema）、data_source（实际主来源）、trace（降级路径）、per_field_source（逐字段来源）

# 输出方（Skill 返回）
return SkillResult(
    skill_id=self.skill_id,
    success=True,
    data=record.data,
    data_source=record.data_source,                 # 主来源，如 "tushare" / "akshare" / "baostock" / "eastmoney"
    meta={"gateway_trace": record.trace},           # 降级轨迹
)
```

- `calls_gateway` 标记约定：经网关取数的 Skill 标 `true`；直连（历史包袱 / 未改造）标 `false` 并登记进 TODO 改造队列。
