# 【股票市场热点解读 - 公开数据源版】

本技能基于公开可得数据源，提供 A 股市场热点的全链条分析服务。从热点识别、深度解读到投资机会挖掘，覆盖政策/行业/概念/个股多维度，所有数据可溯源、带时间戳，帮助投资者快速理解市场主线并制定差异化策略。

**数据源说明：** 本版本使用两类公开可得数据源：

1. **开源金融数据 AkShare**（免费、无需 API Key，聚合东方财富/新浪等公开接口）：行情、板块、成分股、资金流、龙虎榜、涨停池、沪深股通等量化数据
2. **公开网站检索**（WebSearch + WebFetch）：政府网站、交易所官网、巨潮资讯网、权威财经媒体等公开信息

## 输出格式

**支持两种输出格式：**

1. **Markdown 格式** - 默认格式，适合在聊天界面、文档中查看
2. **HTML 格式** - 可在浏览器中打开，支持交互和样式美化

**输出方式（强制要求）：**

- **聊天界面输出**：Markdown 和 HTML 两种格式均在聊天界面完整输出
- **自动保存文件**：每次生成报告时，必须自动保存到以下路径：
  - Markdown: `{workspace}\reports\{报告名称}.md`
  - HTML: `{workspace}\reports\{报告名称}.html`
  - `{workspace}` = 当前工作空间根目录
  - 文件名格式：`股票市场热点解读_{时间范围}_{起始日期} 至{结束日期}.md/html`

**重要：**

- ⚠️ **必须同时生成 Markdown 和 HTML 两种格式**
- ⚠️ **必须自动保存文件，不能仅在聊天界面输出**
- ⚠️ **文件路径必须是 `{workspace}\reports\` 目录**
- ⚠️ **如果 `reports` 目录不存在，必须先创建**

**溯源角标说明：**

- 所有数据均带有溯源角标，如 `[1]`、`[2]`
- 文末统一列出数据来源清单，包含来源名称、更新时间、查询参数
- 角标格式：`[序号] 数据来源 - 更新时间`

## 功能范围

| 功能模块      | 说明                       | 适用场景                |
| --------- | ------------------------ | ------------------- |
| **热点识别**  | 实时抓取政策/行业/个股/概念热点，多源信息聚合 | 了解今天/最近什么概念火、市场在炒什么 |
| **深度解读**  | 成因分析、影响评估、持续性判断、历史对比     | 理解热点背后的逻辑、判断是否可持续   |
| **产业链映射** | 上下游关联梳理，龙头/弹性/补涨标的筛选     | 挖掘热点相关的投资机会、找补涨标的   |
| **资金面追踪** | 主力/北向/南向资金流向，龙虎榜解读       | 判断资金态度、跟随聪明钱        |
| **情绪面分析** | 涨停数/连板高度/炸板率，情绪周期判断      | 判断市场情绪、避免高位接力       |
| **操作建议**  | 短线/中线/长线差异化策略，止盈止损参考     | 获取具体操作思路、风险管理建议     |
| **风险预警**  | 退潮信号/监管风险/业绩证伪/高位接力风险    | 识别潜在风险、避免踩坑         |

## 查询建议

**查询需要具备的要素：**

- **时间范围**：支持灵活时间表达（默认最近 3 天）
  - 相对时间：今天、昨天、最近 3 天、近一周、近 10 天、近一月、近 3 月
  - 周维度：本周、上周、上上周、近 4 周
  - 月维度：本月、上月、上上月、近 3 月、近 6 月
  - 具体日期：2026-04-01 至 2026-04-14
- **热点类型**：政策/行业/概念/个股/事件（可多选）
- **关注板块**：具体概念/行业名称（可选）
- **分析深度**：快速解读/深度分析（默认深度分析）
- **输出格式**：Markdown/HTML（默认 Markdown）

**时间范围解析规则：**
| 用户表达 | 解析逻辑 | 示例（假设今天 2026-04-14 周二） |
|----------|----------|---------------------------|
| 今天 | 当日 | 2026-04-14 |
| 昨天 | 前一日 | 2026-04-13 |
| 最近 X 天/近 X 天 | 今天往前推 X 天（包含今天） | 最近 3 天 → 2026-04-12 至 2026-04-14 |
| 近一周 | 今天往前推 7 天（包含今天） | 2026-04-08 至 2026-04-14 |
| 本周 | 本周一至今 | 2026-04-13（周一）至 2026-04-14 |
| 上周 | **上一个完整自然周（周一至周日）** | **2026-04-06（周一）至 2026-04-12（周日）** |
| 近一月/本月 | 本月 1 日至今 | 2026-04-01 至 2026-04-14 |
| 上月 | 上月 1 日至月末 | 2026-03-01 至 2026-03-31 |
| 近 3 月 | 今天往前推 90 天（包含今天） | 2026-01-15 至 2026-04-14 |

**重要说明：**

- **上周** = 上一个完整自然周（周一 00:00 至 周日 24:00），不是从今天往前推 7 天
- **近一周** = 今天往前推 7 天（包含今天），是滚动的时间窗口
- **本周** = 本周一至今，如果今天是周一，则只有当天数据

**查询写法示例：**

- "今天市场热点是什么"
- "最近什么板块最火，帮我解读一下"
- "低空经济概念怎么看，有什么投资机会"
- "分析本周市场主线和资金流向"
- "XX 政策对哪些板块有利好"
- "用 HTML 格式生成近一周的热点报告"
- "近 3 天涨停股有哪些，溯源要详细"

## 核心工作流程

流程中的工具调用能够并发调用尽量并发调用提速。

### 步骤 1：热点识别与聚合

**目标：** 抓取近期市场热点，按政策/行业/概念/个股分类聚合

**并发调用（公开数据源）：**

```
# 资讯热点（WebSearch）
WebSearch，query="最近3天 A股 财经新闻 热点"，freshness="d3"
WebSearch，query="{关注板块/主题} 政策 通知 意见"，allowed_domains=["gov.cn"]
WebSearch，query="最近3天 个股 公告 异动"，freshness="d3"

# 板块行情排名（AkShare，Python 脚本）
import akshare as ak
ak.stock_board_industry_name_em()   # 行业板块行情排名
ak.stock_board_concept_name_em()    # 概念板块行情排名

# 公司公告（公开网站）
WebFetch，url="http://www.cninfo.com.cn/new/commonUrl?url=disclosure/list/notice"  # 巨潮资讯网公告
```

### 步骤 2：热点深度解读

**目标：** 对识别出的热点进行成因分析、影响评估、持续性判断

**调用（公开数据源）：**

```
WebSearch，query="{热点主题} 研报 分析 逻辑 持续性"
WebFetch，url="东方财富研报中心或权威媒体深度报道 URL"
WebSearch，query="{热点主题} 舆情 市场讨论"
```

### 步骤 3：产业链映射

**目标：** 梳理热点相关的产业链上下游，筛选龙头/弹性/补涨标的

**并发调用（AkShare）：**

```python
import akshare as ak
# 概念/行业成分股
ak.stock_board_concept_cons_em(symbol="{概念名称}")    # 概念成分股
ak.stock_board_industry_cons_em(symbol="{行业名称}")   # 行业成分股
ak.stock_board_industry_name_em()                       # 板块涨幅排名（定位龙头）
```

### 步骤 4：资金面追踪

**目标：** 分析主力资金、北向资金流向，解读龙虎榜

**并发调用（AkShare）：**

```python
import akshare as ak
ak.stock_individual_fund_flow(stock="{股票代码}", market="sh/sz")  # 个股资金流
ak.stock_sector_fund_flow_rank(indicator="今日", sector_type="行业资金流")  # 行业资金流
ak.stock_hsgt_hist_em(symbol="北向资金")          # 沪深股通/北向资金
ak.stock_lhb_detail_em(start_date="...", end_date="...")  # 龙虎榜
```

### 步骤 5：情绪面分析

**目标：** 分析涨停数、连板高度、炸板率，判断情绪周期

**并发调用（AkShare）：**

```python
import akshare as ak
ak.stock_zt_pool_em(date="{YYYYMMDD}")    # 涨停池（含涨停家数、连板高度、炸板）
ak.stock_zt_pool_strong_em(date="{YYYYMMDD}")  # 强势股池（连板高度）
```

### 步骤 6：操作建议生成

**目标：** 基于以上分析，生成短线/中线/长线差异化策略

**调用（AkShare）：**

```python
import akshare as ak
ak.stock_financial_analysis_indicator(symbol="{股票代码}")  # 财务指标（中线判断）
ak.stock_lhb_detail_em(...)                                # 机构席位（机构态度）
```

### 步骤 7：风险预警

**目标：** 识别退潮信号、监管风险、业绩证伪、高位接力风险

**调用：**

```
# 综合风险判断（基于已有数据）
# 无需额外调用，基于步骤 1-5 的数据进行风险识别
# 监管风险可补充 WebSearch 检索交易所问询函、立案调查等信息
```

### 数据获取策略

1. **优先并发调用**：步骤 1（热点识别）、步骤 3（产业链映射）、步骤 4（资金面）、步骤 5（情绪面）建议并发执行
2. **按需调用**：根据热点类型选择数据源（政策热点→政府网站，行业/概念热点→AkShare 板块接口）
3. **超时处理**：单个接口调用超时 30 秒则跳过，不影响整体流程
4. **容错降级**：AkShare 接口因上游站点变动失效时，改用 WebFetch 抓取公开行情页或 baostock 兜底

## 限制

1. **数据时效性**：
   
   - 交易时段数据实时更新，非交易时段数据为最近收盘价
   - 财务数据依赖上市公司披露节奏，可能存在滞后
   - **溯源要求**：所有数据必须标注更新时间

2. **覆盖范围**：
   
   - 覆盖 A 股主要标的；港股数据可通过 AkShare 港股接口补充
   - 部分小众概念/板块可能数据不全
   - **溯源要求**：数据缺失时需明确标注

3. **合规边界**：
   
   - 明确标注"仅供参考，不构成投资建议"
   - 不承诺收益、不推荐具体买卖点
   - 风险提示必须醒目
   - **数据来源必须可追溯**（角标 + 文末清单）

4. **数据源限制**：
   
   - AkShare 聚合的是东方财富/新浪等公开接口，接口可能随上游站点变动失效，需容错降级
   - 公开接口频率有限，建议单次查询间隔 ≥1 秒

5. **输出格式限制**：
   
   - Markdown 格式：适合聊天界面、文档
   - HTML 格式：适合浏览器查看、分享
   - 两种格式内容一致，溯源角标一一对应

## 注意事项

1. **并发调用**：步骤 1、3、4、5 建议并发执行以提升速度
2. **超时处理**：单个接口调用超时 30 秒不影响整体流程
3. **数据验证**：关键数据需交叉验证（如新闻 + 公告 + 行情），标注多个角标
4. **时间范围**：
   - 必须解析用户的时间表达（今天/最近 3 天/本周/上月等）
   - 在报告标题和数据来源部分明确标注分析周期
   - 默认时间范围：最近 3 天
   - **重要：上周 = 上一个完整自然周（周一 00:00 至 周日 24:00），不是从今天往前推 7 天**
   - **重要：近一周** = 今天往前推 7 天（包含今天），是滚动的时间窗口
5. **溯源角标**：
   - 所有数据类陈述必须标注角标
   - 判断类陈述建议标注角标
   - 文末必须包含完整的溯源清单
6. **格式要求（强制）**：
   - ⚠️ **必须同时输出 Markdown 和 HTML 两种格式**
