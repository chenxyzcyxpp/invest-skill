# 宏观经济选股分析

把宏观经济变量（增长 / 流动性 / 通胀 / 外部环境 / 就业）系统拆解成可观测指标，再映射到 A 股行业景气与风格轮动，最终产出一份"先看结论、再列证据、给配置"的宏观—权益投资分析报告。

## 何时使用

- 用户从宏观/经济视角问"A 股怎么看""该配什么""现在什么风格占优"。
- 用户给出或要求拉取 PMI、CPI、PPI、社融、M1/M2、LPR、失业率、美债、美元、美国 CPI/PCE 等数据并希望解读对股市的影响。
- 用户需要一份**月度/当前时点**的宏观配置报告（仓位、风格、行业超低配）。
- 用户要做宏观驱动的行业比较、板块轮动、大类资产配置。

## 核心方法论（三句话）

1. 股票定价 = 盈利（EPS）× 折现率（无风险利率 + 风险溢价）；宏观只解决"盈利方向"与"估值方向"两条线。
2. 用**增长、流动性、通胀、外部、就业**五个维度给经济画像，再套"宏观景气时钟"定象限。
3. 每个宏观信号都有明确受益/受损板块（见下方「指标 → 行业/风格映射」），结论必须落到具体行业与风格，不能停在"经济向好/承压"这种空话。

## 执行步骤

当用户请求宏观分析/报告时，按以下顺序执行：

### 步骤 1：获取实时宏观数据
优先顺序：**实时 MCP 源 > 离线脚本兜底**。

- **首选实时源**（已连接，优先用）：
  - `mx-ds-mcp`（东方财富妙想）：通过宏观问答/数据接口获取 PMI、CPI/PPI、社融、M1/M2、LPR、美债、美元、美国通胀等最新值。
  - `tdx-connector`（通达信）：`wenda_macro_query` 宏观问答、`tdx_quotes` 等，用于高频与市场验证。
- **离线兜底**：运行 `scripts/macro_snapshot.py` 生成 JSON 快照（基于 akshare）：
  ```bash
  python scripts/macro_snapshot.py --out snapshot.json --pretty
  ```
  用托管 venv：`C:/Users/86988/.workbuddy/binaries/python/envs/default/Scripts/python.exe`
  - 该脚本已对停更的老接口自动改用更新更及时的 `*_yearly`/报告型接口，并对每个指标标注 `stale`（数据滞后）。若 `meta.stale` 中有指标，**必须提示用户该数据可能滞后，并用 MCP 实时源交叉验证**。

### 步骤 2：经济画像（五维度打分）
对照下方「指标 → 行业/风格映射」与实时数据，给每个维度打方向（↑/↓/→）：
- **增长**：制造业/非制造业 PMI、工业增加值、社零、出口、库存四象限。
- **流动性**：社融脉冲、M1/M2 与剪刀差、LPR/利率、DR007。
- **通胀**：CPI、PPI、PPI−CPI 剪刀差、美国 CPI/核心 PCE。
- **外部**：美债 10Y、中美利差、美元指数、美国需求（零售/地产）。
- **就业**：城镇调查失业率（尤其青年）、政策刺激概率。

### 步骤 3：定位宏观景气时钟象限
组合（增长 × 通胀）+ 流动性调节（见下方「宏观景气时钟速查」）：
- 复苏 → 成长/科技、券商、早周期
- 过热 → 资源/周期/能源、有色
- 滞胀 → 黄金、必选消费、高股息、公用事业
- 衰退 → 债券、防御红利、公用事业、现金
- 流动性作为放大器：宽信用强化价值/大盘，宽货币紧信用强化小盘/主题。

### 步骤 4：产出报告
严格套用下方「报告模板」：
1. 一句话结论（大势 / 仓位 / 风格 / 核心矛盾）。
2. 宏观景气定位（四象限打分表）。
3. 五维度证据（增长/流动性/通胀/外部/就业），每个结论带**数值 + 数据日期**。
4. 资产配置建议：**行业超低配表**（勾选映射表对应结论，写清宏观逻辑）。
5. 风险与跟踪日历（未来 2–4 周关键数据 + stale 提示）。
6. 数据来源与免责。

**格式纪律**：先给结论再给证据；所有数值必须标数据日期；stale 数据必须显式提示；不引用任何特定机构或个人的名称（框架方法论归公共知识）。

| 象限 | 条件 | 风格/行业 |

| 过热 | 增长↑、通胀↑ | 资源/周期/能源、有色 |
| 滞胀 | 增长↓、通胀↑ | 黄金、必选消费、高股息、公用事业 |

## 指标 → 行业/风格映射

> 报告生成时，根据实时指标方向勾选对应结论。以下为通用宏观—权益映射（公共投资知识）。

**增长维度**
- 生产高频 ↑：钢铁、化工、煤炭、上游周期占优；防御相对跑输。
- 消费高频 ↑：汽车、地产链、纺服、白酒/消费占优。
- 出口高频 ↑：家电、纺服、电子、航运/集运占优。
- 制造业 PMI ↑（>50 且环比↑）：机械、建材、化工、顺周期占优；高估值长久期相对弱。
- 非制造业 PMI ↑：出行链、社服、消费服务占优。
- 库存：被动去库 → 主动补库：周期股最佳布局窗口。

**流动性维度**
- 社融脉冲 ↑：银行、地产链、券商、顺周期占优；防御红利相对弱。
- M1 同比 ↑ / M1−M2 剪刀差走阔：周期、成长、风险偏好回升；纯债相对弱。
- M2 高、M1 低（资金淤积）：债券、高股息、公用事业占优；中小盘题材相对弱。
- 利率 ↓（DR007、10Y 国债、LPR）：成长、券商、地产占优；银行息差承压。
- 宽货币 + 紧信用：小盘成长、主题行情占优；大盘价值相对弱。

**通胀维度**
- PPI−CPI 剪刀差走阔（PPI↑）：煤炭、钢铁、有色、化工（上游）占优；中下游制造、必选相对弱。
- PPI 回落、CPI 温和：中下游制造、消费（毛利修复）占优；上游资源相对弱。
- 食品 CPI ↑（猪价/菜价）：养殖、农业占优；必选消费（成本端）承压。
- 美通胀高（美联储偏鹰）：美元、银行（息差）、价值占优；成长股、黄金相对弱。
- 美通胀回落（降息预期）：成长股、黄金、新兴市场占优；美元、价值相对弱。

**外部环境维度**
- 美国需求强 / 地产景气：出口链（家电、纺服、轻工、电子）占优。
- 美债收益率 ↓（10Y）：成长、黄金、A 股估值占优；银行息差承压。
- 美元指数 ↓：新兴市场、有色、A 股风险偏好占优；出口（汇率角度）承压。
- 美就业强（工资粘性）：美联储偏鹰 → 价值/美元占优；成长相对弱。

**就业与政策维度**
- 调查失业率 ↑（尤其青年）：券商、地产、基建（政策博弈）占优；消费（预期弱）承压。
- 服务业吸纳就业：服务业龙头、灵活用工占优；传统二产相对弱。

## 报告模板

> 所有结论须基于**实时数据**，标注数据日期与来源；方法论归公共知识，不引用任何特定机构或个人。

**标题**：A 股宏观配置月报 · {YYYY-MM}
生成时间：{now} ｜ 数据截止：{data_asof} ｜ 数据来源：{sources}

1. **一句话结论**：大势（复苏/过热/滞胀/衰退/震荡）｜仓位（积极/中性/防御，权益 {xx%}）｜风格主线（成长/价值/周期/防御红利）｜核心矛盾（1 句最大变量）。
2. **宏观景气定位**（四象限打分表）：维度 / 当前信号 / 方向 / 关键数值（数据日期）。
3. **增长维度证据**：生产（PMI 制造业 + 工业增加值同比）、消费（社零同比 + 非制造业 PMI）、出口（出口/进口同比）、库存周期（PMI 新订单 − 产成品库存定位四象限）。
4. **流动性维度证据**：社融脉冲（增量 + 存量同比趋势，领先 PMI 约 2 季度）、M1/M2（同比 + 剪刀差）、利率（LPR 1Y/5Y、10Y 国债，与 PMI 同向）。
5. **通胀维度证据**：中国 CPI/PPI 及 PPI−CPI 剪刀差；美国 CPI/核心 PCE/ISM → 美联储路径。
6. **外部环境**：美债 10Y、中美利差、美元指数 → 对 A 股成长/黄金/新兴市场影响；美国需求 → 出口链。
7. **就业与政策**：城镇调查失业率（青年）、稳增长政策预期、降准降息/财政/地产托底概率。
8. **资产配置建议**（核心交付）：A 股仓位与风格 + **行业超低配表**（周期/资源、银行地产链券商、成长科技、消费、医药养老、黄金资源、公用事业高股息、出口链 — 各列方向 + 宏观逻辑）。
9. **风险与跟踪日历**：已识别风险、未来 2–4 周关键数据（PMI 月初、CPI/PPI 月中、社融中旬、LPR 每月20日、美国 CPI/非农月初）、stale 提示。
10. **附录**：数据来源（mx-ds-mcp / tdx-connector 优先，scripts/macro_snapshot.py 兜底）与免责（宏观推演非投资建议，需结合个股基本面与估值）。
