# 工具使用指南

## 政策定义

本技能仅处理以下类型：
- **法律法规**：全国人大、国务院颁布的法律、行政法规
- **部门规章**：各部委发布的规章、办法、规定
- **规范性文件**：国务院及各部门发布的通知、意见、方案、行动计划
- **地方政策**：省、市、自治区政府及部门发布的政策文件
- **产业政策**：针对特定行业的支持、规范、限制类政策
- **区域政策**：自贸区、新区、特区等区域发展政策

政策文件特征：有明确发布机构、正式文号（如"国发〔2026〕X 号"）、政策名称和实施时间。

## 数据源清单（公开可得）

本技能使用公开政府网站与权威媒体数据源，通过 `WebSearch`（检索）与 `WebFetch`（抓取原文）获取。**不依赖任何商业数据库或 API Key。**

## 检索方法

### 基本检索（WebSearch）

```
WebSearch，query="近一月 人工智能 产业政策 通知 意见"，allowed_domains=["gov.cn"]
WebSearch，query="2026年 新能源汽车 财政补贴 政策"，allowed_domains=["www.gov.cn", "www.mof.gov.cn"]
WebSearch，query="某市 最新 产业扶持 政策 方案"
```

- 关键词务必叠加政策特征词：政策、通知、意见、方案、规划、办法、规定、决定、条例、公报、行动方案、指导意见
- 日期范围可用 `freshness` 参数（d7 / d30 / d365）或直接写在 query 中
- 政策类型（宏观/行业/区域/财政/货币/环保/产业）可追加到 query 中

### 原文抓取（WebFetch）

检索到政策条目后，用 `WebFetch` 抓取官方原文页面，提取：政策标题、发布机构、文号、发布日期、正文。

```
WebFetch，url="https://www.gov.cn/zhengce/...具体政策页"
```

### 溯源要求

每条政策必须记录：
- 来源 URL（一手官方页面优先）
- 发布机构
- 发布时间（精确到日，能到时分秒更佳）
- 文号（如有）

## 严格排除的数据（非本技能范围）

以下内容**不属于**本技能范围，即使检索命中也应跳过：

- **统计数据**：CPI / PPI / GDP / PMI 等经济数据
- **券商研报**：卖方研究报告、评级观点
- **股票行情 / 大宗商品价格**
- **公司公告 / 财报**
- **财经评论**（非官方政策解读的媒体观点文章）

## 查询要素

| 要素 | 是否必填 | 说明 |
|------|---------|------|
| 关键词 keyWord | 必填 | 行业或政策主题 |
| 日期范围 | 可选 | 未指定默认近一月 |
| 政策类型 policyType | 可选 | 宏观/行业/区域等 |
| 地域范围 region | 可选 | 全国性/省级/市级 |

## 正确查询示例

```
查询近一周 AI 行业相关政策
查询最新的货币政策动态
上海自贸区最新政策
查询近一月环保政策文件
超低排放相关政策
```

## 错误查询（非本技能范围）

```
查询近一周 CPI 数据          → 应用 finance-data
钢铁行业研报观点              → 应用 industry-research-summary
今天钢铁板块涨幅              → 应用 finance-data
碳酸锂价格走势                → 应用 finance-data
```
