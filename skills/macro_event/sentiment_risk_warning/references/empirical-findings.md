# 实证结论速查（2026-10-13 外部对比评审）

> 来源：用户发来的一份更成熟的外部版「舆情风险预警SKILL.md」（含 800 日 × 5 股 × 8 种子 walk-forward 实测、消融、代码评审修复记录），与本 skill v1.0.0 逐条对比后提取的可复用证据。升级特征集/窗口/验证口径前先读本文件。

## 1. 样本量是第一瓶颈（决定特征价值判断）

同一标的（江丰电子 300666），只改回看天数：

| 回看天数 | 样本外 R² |
|---|---|
| 250 日 | -0.083 |
| 500 日 | +0.120 |
| 800 日 | +0.181（最优） |
| 1200 日 | +0.102（回落） |

- 250 日样本会误杀 `vol_20d`（ARCH 先验有效特征）：250 日判「无增益」，800 日判 8/8 种子全胜、R² 均值 +0.0174。
- 本 skill 默认 1250 日（60 月）落在回落区附近；改动窗口前先按样本量复验。

## 2. 特征消融结论（哪些特征该删/该验）

| 特征 | 实测结论 |
|---|---|
| `usdcny` | 命令行单值写死整条序列，Z-score 后恒 0，零信息量（曾冒充有效因子） |
| `chg_point` | 与 `pct_chg` 完全共线（点数 = pct% × 昨收），仅量纲差异 |
| `index_sh` | 非平稳点位，构成时间代理变量 |
| `amount`/`volume` 绝对值 | 非平稳 → 改 `amount_rel`（额/20日均值） |
| `sh_quantile` | 12/12 种子拖累，噪声 → 不生成 |
| `mkt_vol_20d` | R² 均值 -0.0406，拖累 → 不默认启用 |
| `vol_20d` | 第一重要特征（重要性 0.37~0.66），800 日下默认开启 |
| `ind_pct` | 方向 60.3%，5/5 优于均值基线 → 可选 |

本 skill v1.0.0 的 `sh_quantile`/`usdcny_pct`/`crowding_score` 均未做过消融验证，升级前必须补验。

## 3. 舆情双通道（防口径虚标）

- 单通道（仅股吧）在沙箱/受限网络下 `opinion_index` 恒 0 → 模型实际是纯量价模型，属口径虚标。
- 双通道设计：① `guba` 东财股吧（覆盖 <50% 交易日自动跳过）；② `proxy` 融资融券/龙虎榜/股东户数（日频，融资覆盖 99%+，可回溯 2011 至今）。
- 大盘模式：涨跌家数推导「市场情绪广度」=(上涨−下跌)/(上涨+下跌) 作为日频舆情，真实连续可比。
- 股吧文本指数必须用加权均值（分母为权重和，值域约 [-1,1]）；求和会让指数与发帖量成正比（与 `amount_rel` 共线），且低样本日记中性 0。

## 4. 舆情维度真实增量（口径修正后）

800 日 × 5 股 × 8 种子 walk-forward：

- 有效成分是 `margin_net_buy` = (融资买入−偿还) / 融资余额的20日均值（「加杠杆速度」单一维度），ΔR²=+0.0153，5/5 股、90% 种子。
- 旧口径（净买入/净买入自身20日均值，自我归一化）ΔR²=+0.0095，4/5 股、75% 种子，且长电科技拖累（-0.0107、0/8 种子）；新口径下长电翻正（+0.0048、6/8）。
- 龙虎榜（事件稀疏）、股东户数（低频）无效甚至拖累。
- 定位：量价之外的补充确认信号，不是预警主力；对突发消息面捕捉弱于人工读新闻。

## 5. walk-forward 验证要点

- 每折训练集只含该折测试点之前的数据；标准化参数仅由训练集估计（全样本 z-score 会穿越 CV 边界，实测偏移 0.29σ）。
- 填充（ffill/bfill）必须在每折内部完成，禁止 CV 切分前对全序列 bfill（用未来值=泄露）。
- 滚动窗口预热期 NaN 禁止填 0（amount_rel 填 0 = 「成交量是均值 0 倍」，Z-score 后 -3.59σ；vol_20d 填 0 → -4.97σ）。
- 日波动率 AC1 ≈ 0.34~0.67，R² 绝对值天然偏低；必须对比基线：均值基线 R²≈-0.04~-0.22，持续性基线 R²≈-0.12~-2.25。
- 800 日 + 5 特征实测：5/5 优于均值基线、5/5 优于持续性基线，方向准确率 58.7%~74.4%。

## 6. 数据源与工程坑

- 北交所代码前缀映射：8/4/920 开头不可笼统归 .SZ，按前缀分档（沪/北/深互不重叠）。
- 数据源静默降级比报错危险：接口返回空 DataFrame（非 None）会被判成「有数据但全常数」→ 整列置 0 → 基线被削弱、增益虚高近 3 倍。任何「特征无效」结论前必须先确认该列有变异。
- 银河源换手率 = 成交量 ÷ 流通股本 × 100（按生效日分段匹配）；申万行业指数 511 个，经行业成分股映射（日期对齐率 99.6%）。
