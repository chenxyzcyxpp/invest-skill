# 舆情风险预警（舆情指数 + 随机森林）

## Overview

本 skill 是一套可直接运行的 A 股风险预警方法：用「市场/个股舆情 + 量价相对特征」训练随机森林，预测下一交易日的波动风险并做分级。大盘模式沙箱内可运行；个股模式需要本机网络访问东方财富；所有报告输出实操化结论。

**重要原则：优先使用相对值、比率、分位数，规避原始绝对值带来的时序非平稳、量级漂移问题。**

## 触发条件

- 用户要求「舆情风险预警」「波动率预测」「风险评分」「明日波动风险」「risk-off 预警」
- 需要在大盘（上证综指）或个股层面给出下一交易日风险等级
- 需要结合股吧舆情 / 新闻情感判断市场情绪方向

**Don't use for:** 常规看盘（tail-market-leader）、量化选股与个股深度分析（racing-quant-ai）、事件驱动选股（event-driven）。

## 一、框架原理

### 1.1 建模目标

- **预测目标**：股票/指数日波动率 = (最高 − 最低) / 昨收 × 100%，波动率表征波动风险。
- **训练范式**：t−1 日特征预测 t 日波动率标签，严格前向预测，禁止未来数据泄露。
- **模型**：随机森林回归，参数 `n_estimators=103, min_samples_split=3, min_samples_leaf=2, max_depth=10`；无 scikit-learn 环境自动回退等价 numpy 实现（bootstrap 采样 + 随机特征子集递归分割 + 叶子均值）。
- **预处理流水线**：异常值 Winsor 缩尾 → VIF 共线性过滤 → Z-score 标准化。
- **风险分级**：预测波动率 >4% 高风险 / 2~4% 中风险 / <2% 低风险；映射综合风险分 0-100（分段线性，封顶）。
- **训练窗口**：滚动时序窗口，默认 60 个月，尽可能完整覆盖一轮牛熊周期；支持配置 36/60 个月；有效样本不足 200 时自动缩减窗口，并降级为简易统计模型（近 20 日波动率 70 分位）。
- **舆情特征采集窗口**：默认取近 30 天文本数据。

### 1.2 舆情指数构建

- **大盘模式**：市场情绪广度 = (上涨家数 − 下跌家数) / (上涨家数 + 下跌家数)，结合资讯新闻 TF-IDF 加权情感交叉校验，合成 `opinion_index`。
- **个股模式**：舆情**双通道**——①股吧帖子按日聚合；②个股新闻（东财 search-api，keyword=股票名称）按日聚合；两通道各自情感计算后逐日加权合成（默认 0.5/0.5）。情感词典（支持否定词、程度副词），Σ(TF-IDF权重 × 单文本情感值) 得到舆情指数；语料稀疏（单日帖数 < 3）退化为情感求和。股吧语料稀疏或不可达时，新闻通道仍可独立工作，避免 opinion 恒 0 的口径虚标。
- **必须双通道，禁止单通道**：舆情源仅股吧时，股吧不可达会致 `opinion_index` 整列恒 0 —— 口径虚标（纯量价冒充含舆情）。个股模式须加代理通道自动回退：银河融资融券 / 龙虎榜 / 股东户数（日频可回溯 2011，融资覆盖 99%+）。proxy 通道有效成分为 `margin_net_buy` = (融资买入−偿还)/融资余额20日均值（800日×5股×8种子 walk-forward 实测 ΔR²=+0.0153、5/5 股、90% 种子）；**禁止自我归一化**（净买入/净买入自身均值）。新闻通道（2026-10-15 加入）为股吧之外的第二独立文本通道，与 proxy 通道互补。

### 1.3 特征集（区分大盘模式 / 个股模式）

不再直接使用原始指数点位、原始成交金额、涨跌绝对点数 chg_point。

**模式 A：大盘模式（上证/深成/创业板三指数波动率预测，特征通用）**

| 特征 | 含义 | 说明 |
|---|---|---|
| opinion_index | 舆情指数 | 正看多、负看空，合成平稳指标（训练期历史舆情通常不可得，作为当期校验信号输出，不入训练矩阵） |
| sh_quantile | 上证点位窗口分位数 | 过去 60 个月收盘分位数，替代原始 index_sh 绝对点位，表征市场水位 |
| turnover | 流动性代理 | 成交额 / 指数点位 |
| amount_rel | 成交额相对倍数 | 当日成交额 / 过去 20 日平均成交额，消除市场扩容量级漂移 |
| pct_chg | 上证涨跌幅 (%) | 相对变化，替代涨跌点数 chg_point |
| usdcny_pct | 美元兑人民币涨跌幅 (%) | 汇率冲击，使用变化幅度而非汇率绝对值 |
| vol_20d | 20 日历史波动率 | 刻画波动惯性 |
| breadth | 涨跌家数占比 | 市场情绪广度，和舆情指数交叉验证 |

**模式 B：个股模式（单标的波动率预测）**

移除上证点位、汇率特征；替换为标的自身与板块相对特征。

| 特征 | 含义 | 说明 |
|---|---|---|
| opinion_index | 个股舆情指数 | 股吧情感合成指标（历史语料可得时入特征，否则当期信号） |
| turnover | 换手率 (%) | 标的原生相对指标 |
| amount_rel | 成交额相对倍数 | 当日成交额 / 过去 20 日平均成交额 |
| pct_chg | 个股涨跌幅 (%) | |
| ind_pct | 所属行业指数涨跌幅 (%) | 表征板块环境，替代上证绝对点位 |
| vol_20d | 个股 20 日历史波动率 | 波动惯性 |
| crowding_score | 拥挤度得分 | 内置代理：换手率 250 日分位数；可被外部 invest-skill 拥挤度输出覆盖 |

## 二、两种运行模式

### 模式 A：大盘研判（三指数可选）— 沙箱可直接跑

依赖 `scripts/market_risk.py`，默认支持三指数分别研判：**上证综指（000001.SH）/ 深证成指（399001.SZ）/ 创业板指（399006.SZ）**。单指数研判与三指数汇总对比两种用法，均可传 `--code/--name` 扩展任意指数代码。

**Agent 执行流程（单指数，以上证为例）：**

1. 调 `tdx_kline(code="000001", setcode="1", period="4", wantNum=1250)` 取上证 K 线（适配 60 个月约 1250 个交易日），落盘 `sh_index_kline.txt`。
2. 调 `wenda_news_query(name="A股", bdate=近3周, edate=今日)` 获取新闻，输出 `news.json`。
3. 调用接口获取市场快照，组装 `snapshot.json`（字段见第四节），计算衍生相对特征（分位数、amount_rel、usdcny_pct、vol_20d、breadth）。
4. 执行脚本：

```bash
PYTHONIOENCODING=utf-8 <venv>/Scripts/python.exe \
"<skill>/scripts/market_risk.py" \
--kline sh_index_kline.txt --news news.json \
--snapshot snapshot.json --out . \
--code 000001.SH --name 上证综指
```

- 不传 `--kline/--news`，使用内置演示数据直接输出报告。
- `--code/--name` 控制指数标识与报告文件名（传 code 输出 `risk_report_market_<code>.txt/json`，缺省沿用旧文件名）。
- `--months 36|60` 控制滚动窗口；`--news-window` 控制舆情采集窗口天数。
- **特征表三指数天然通用**（sh_quantile 为「指数点位窗口分位数」，turnover/pct_chg 均为相对量），无需改动。

**真实数据一键采集 + 三指数对比（实战链路，2026-10-09 已跑通）：**

```bash
# 1) 采集：三指数60月K线 + 涨跌分布 + 成交额 + 主力资金 + 新闻 + 汇率
python3 <skill>/scripts/market_collect.py --out /tmp/mr_live
#    落盘 kline_<code>.json + snapshot_<code>.json + news.json（上证另存旧名兼容）

# 2a) 三指数汇总对比（推荐，一次看三指数波动率/风险分并列 + 风险梯度）
PYTHONIOENCODING=utf-8 python3 <skill>/scripts/market_risk.py \
    --compare /tmp/mr_live --out /tmp/mr_live

# 2b) 或单指数研判（逐只看详细报告）
PYTHONIOENCODING=utf-8 python3 <skill>/scripts/market_risk.py \
    --kline /tmp/mr_live/kline_399006.SZ.json --news /tmp/mr_live/news.json \
    --snapshot /tmp/mr_live/snapshot_399006.SZ.json --out /tmp/mr_live \
    --code 399006.SZ --name 创业板指
```

> 采集脚本自动从 `~/.hermes/config.yaml` 提取 Tushare token（本地 tushare 库直连，
> 避免 MCP 大响应截断）；Tushare `pro.news`/`fx_daily` 无权限，新闻走东财搜索、
> 汇率用 7.15 中性兜底；东财 push2ex 本机可用（push2his 不可用）。
> 舆情口径为全市场（新闻 + 涨跌分布），三指数共用同一新闻源，指数层面差异体现在各自量价特征。
> 各接口单位口径与解读要点详见 `references/data-sources.md` 第六节。

### 模式 B：个股研判 — 需本机网络可达东方财富

依赖 `scripts/stock_risk_scorer/cli.py`

```bash
# 真实行情 + 股吧 + 新闻双通道（--days 建议 1250，匹配默认 60 个月滚动窗口）
<venv>/Scripts/python.exe -m stock_risk_scorer.cli --code 300666 --days 1250

# 离线自测（内置演示数据）
<venv>/Scripts/python.exe -m stock_risk_scorer.cli --code 300666 --self-test

# 传入自备股吧语料（CSV：date,text）
<venv>/Scripts/python.exe -m stock_risk_scorer.cli --code 300666 --posts my_guba.csv --days 1250

# 关闭新闻通道（仅用股吧）
<venv>/Scripts/python.exe -m stock_risk_scorer.cli --code 300666 --no-news --days 1250

# 多股票批量（逗号分隔）
<venv>/Scripts/python.exe -m stock_risk_scorer.cli --code 300666,600584,002472
```

输出：控制台结论 + `risk_report_<code>.html` + `risk_report_<code>.json`。

**舆情双通道**：默认同时抓取股吧（guba.eastmoney.com）与个股新闻（东财 search-api，keyword=股票名称/代码），两通道逐日按 0.5/0.5 加权合成 `opinion_index`；新闻通道失败或 `--no-news` 时自动降级为仅股吧并标注，不伪造数据。K 线取数东财 push2his 失败自动回退 Tushare（本机实测可用，换手率取自 daily_basic），回退行为在报告标注。

## 五、报告解读要点

1. **输出**：下一交易日预测波动率、风险等级、综合风险分 0-100。
2. **舆情维度**：舆情指数 + 市场广度同步转负，即使预测波动率不高，也要警惕短线 risk-off。
3. **特征重要性**：查看哪些因子主导本次预警。
4. **对比历史真实波动率与预测值**，评估模型拟合质量（脚本输出 OOS MAE 与相关系数 r）。
5. **舆情必须给观点概括，不只给数值**（用户明确偏好）：除舆情指数与文本样本数外，须补一段简短观点总结——按时间归类偏多/偏空/中性信号、点出营销稿等噪音来源、给出一句方向性判断（如「防守中的修复」）。只写「舆情指数 +0.99、文本样本 18 条」缺乏直观感受，用户会反感。个股模式报告已自动列出「近期新闻标题」与各通道样本数，解读时结合新闻标题提炼方向，勿只报合成数值。

## 六、能力边界（必须告知用户）

1. 指数天然波动率低于个股，优先参考综合风险分、舆情方向，不要只看绝对波动率阈值。
2. 大盘、个股舆情数据源口径不一致，不可直接横向对比风险分数。
3. 训练窗口默认 60 个月尽量覆盖牛熊，但历史不能完全复刻未来；对黑天鹅突发事件预测能力有限，重大事件需要人工二次研判。**⚠️ 预测力口径（2026-10-13 修正）：旧版宣称的「样本外 R²≈0.52」实为单次样本内拟合值，无预测意义，已废弃。walk-forward 样本外实测 R²≈-0.16~+0.17，属弱预测，只适合相对异常识别与仓位提醒，不能当作精确的次日波动率预测；判断有效性必须对比均值基线/持续性基线（证据见 references/empirical-findings.md）。**
4. 股吧存在水军噪声干扰；长周期舆情需要用户自备历史语料。
5. 原始输入不使用 Wind，数据源为通达信、东方财富。
6. 不构成投资建议，仅作为前置风险信号，需要结合其他策略交叉验证。

## 七、工程约束（开发规范）

1. 训练使用滚动时序窗口，默认 60 个月，不做全量历史一次性训练；样本不足自动缩减窗口并降级。
2. 原始绝对值仅作为数据源输入；模型输入全部转换为相对值、比率、窗口分位数。
3. 预处理流水线：Winsor 异常缩尾 → VIF 共线性过滤 → Z-score 标准化。
4. 两套模式特征配置隔离，大盘、个股不可混用特征列表。
5. 全部失败场景返回明确错误，禁止伪造预测结果。

**补充说明**：取数接口 days 参数默认 1250 交易日，对应约 60 个月；允许外部参数覆盖窗口大小。

## Common Pitfalls

1. **禁止编造数据**。任何行情/舆情/预测数值必须来自脚本计算；数据源失败时脚本会报错退出，Agent 不得用估算值替代，须如实标注「数据获取失败」。
2. **大盘/个股特征不可混用**。模式 A 有 sh_quantile/usdcny_pct，模式 B 有 ind_pct/crowding_score；两套特征列表隔离，禁止交叉套用。
3. **不要只报预测波动率**。指数波动率天然偏低，必须同时给综合风险分与舆情方向，否则结论误导。
4. **样本不足必降级**。有效样本 < 200 时脚本自动降级为简易统计模型并在报告标注，Agent 不要按随机森林口径解读降级输出的特征重要性（此时为占位）。
5. **个股模式离线自测不等于真实行情**。`--self-test` 用内置演示数据，仅用于验证管线；真实预警必须走 `--code xxx` 真实取数，网络不可达时如实报告。
6. **舆情口径不一致不可横比**。大盘用新闻 TF-IDF、个股用股吧情感（+个股新闻），两者分数无横向可比性。
7. **个股新闻通道与股吧是独立通道，禁止混为一谈**。两通道各自按日聚合情感后加权合成（默认 0.5/0.5）；新闻通道失败时报告必须标注降级，禁止把「仅股吧」冒充「双通道」。
8. **个股模式 K 线有双数据源回退**。东财 push2his 不可达时自动回退 Tushare（daily+daily_basic，amount 千元→元），报告标注实际使用的数据源；两个数据源都失败才报错。
9. **skill 升级后同步调用方**。若本 skill 被 cron 挂载，升级 SKILL.md 或脚本后必须同步 cron prompt 中的口径说明与输出模板。
10. **首日标签必须剔除，不能置 0**。波动率标签 = (高-低)/昨收，首日无真实昨收；`label[0]=0` 会作为伪样本污染训练集（QA 实测逐点核对发现差异）。必须置 NaN 并在特征过滤时剔除（大盘/个股 features 均已按此实现，修改时勿回退）。
11. **演示数据种子禁用 `hash()`**。Python 字符串 hash 受 PYTHONHASHSEED 影响、进程间不稳定，会导致 `--self-test` 结果漂移无法复现；必须用代码数字派生种子（`int(re.sub(r"\D","",code))`，已实现）。
12. **numpy 回退随机森林勿做逐日滚动重训 OOS**。60 次重训 × 103 棵 ≈ 11 分钟超时；改用「85% 训练 / 后 15% 前向预测」单次训练（完整 1250 日仅 12 秒），训练段与验证段时序不重叠，严格无泄露，口径在报告中标注为「固定模型前向验证」。
13. **大盘预警默认三指数汇总对比，禁止只报上证**（用户明确要求）。每次大盘预警先走 `market_collect.py` + `--compare` 三指数（上证/深成/创业板）并列对比；单指数研判仅在需要看某一只详细报告时使用。
14. **舆情不能只给数值不给观点**。报告仅写「舆情指数 +0.99、文本样本 18 条」缺乏直观感受（用户已明确反馈）；必须补观点概括（按时间归类的偏多/偏空信号 + 营销稿等噪音来源 + 方向性一句话）。
15. **样本内 R² 不等于样本外预测力**。报告/文档中的「R²≈0.52」是单次样本内拟合值，无预测意义；真实 walk-forward 样本外 R²≈-0.16~+0.17（弱预测）。能力表述必须用 walk-forward + 基线对照，不得引用样本内指标（证据见 references/empirical-findings.md §1/§5）。
16. **舆情单通道有口径虚标风险**。个股模式仅股吧通道，网络不可达时 opinion_index 恒 0，模型实际退化为纯量价模型却仍宣称「舆情预警」。应加代理通道（融资融券/龙虎榜/股东户数）自动回退，且报告标注实际使用的通道语义（见 references/empirical-findings.md §3）。
17. **默认窗口未必最优，样本量决定特征判断**。实测 250→-0.083、500→+0.120、800→+0.181、1200→+0.102（800 日最优）；250 日样本会误杀 vol_20d 这类 ARCH 有效特征。默认 1250 日落在回落区，改动窗口前先按样本量复验。
18. **特征价值未经消融验证勿轻信「特征重要性」**。sh_quantile 实测 12/12 种子拖累、usdcny 恒 0 零信息、chg_point 与 pct_chg 共线；报告中的重要性排序只是拟合视角，改特征集前先跑消融验证列的真实变异。
19. **个股舆情新闻通道已落地（2026-10-15），但 proxy 通道未实现**。SKILL.md §1.2 宣称「必须双通道+银河融资融券/龙虎榜/股东户数代理、margin_net_buy」及 `--sentiment auto|guba|proxy|none` 参数，但实测安装代码 scripts/stock_risk_scorer/cli.py 无 proxy 分支、无 --sentiment 参数。当前已实现的通道为：股吧 + 个股新闻（东财 search-api，默认 0.5/0.5 合成）+ K线 Tushare 回退。任何依赖 proxy/margin_net_buy 的宣称，先核对 cli.py/data.py 是否已落地；未落地前个股模式实际是「股吧+新闻双文本通道，网络受限时退化为纯量价」。
