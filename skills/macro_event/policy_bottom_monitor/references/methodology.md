# 回测口径与双轴分类定义（稳定文件）

## 1. 回测口径

与 `a_share_bottom_monitor/references/methodology.md` 保持一致，差异仅在于触发事件从
"量价信号"换成"政策事件"：

- **触发日T**：政策事件公告日（若为非交易日或盘后发布，取下一交易日）。
- **收益口径**：T日收盘买入，持有5/20/60个交易日，收益 = close[T+N]/close[T] − 1。
- **去重**：同一组合内的多个政策事件（间隔≤10交易日）归并为一次组合归因，
  组合归因以组合首个事件日为T0；单条归因与组合归因双轨并存，**分类以组合为准**。
- **运气线**：上证全样本每5天采样（step5）的60日收益分布，中位数−0.2%、胜率50%，
  25分位−5.9%、75分位+5.3%。政策后60日收益显著高于此才判定"有效"。
- **基准指数**：上证为主（2008年起数据完整）；2014年起补充深成/创业板/中证2000。
- **早期位置缺口**：2008-2013年指数数据不足250日时，位置档为N/A，仅按工具轴分级。

## 2. 政策事件验证纪律

- **日期必须交叉验证**：政策日指数应出现与政策性质相符的异常波动（如印花税类政策
  当日大涨、熔断类当日暴跌），K线波动幅度与新闻确认一致才录入。
- **无法验证的事件不录入**（宁可少一条，不可错一条）。
- 来源：东财搜索API（近期新闻）、搜狗网页搜索（历史事件）、指数K线交叉验证。

## 3. 工具强度轴定义

| 等级 | 定义 | 示例 |
|------|------|------|
| S | 增量资金直接入市（央行新工具/平准基金/国家队大规模买入） | SFISF、证金2000亿、汇金扩大ETF增持 |
| A | 货币财政强工具（降准降息/财政扩张/国家队常规增持） | 2019-01降准、2024-02汇金、2025-04护盘 |
| B | 交易成本+规则（印花税/暂停IPO/减持/回购新规） | 2008/2023印花税、2012暂停IPO |
| C | 表态喊话（政治局/金融委/部委/监管表态） | 2022-03金融委、2023-07政治局 |
| D | 机制性紧缩（限制流动性类机制） | 2016-01熔断 |

## 4. 位置适配度轴定义（上证口径）

| 位置档 | 定义 | 修正 |
|--------|------|------|
| 深跌区 | 距250日高点回撤≤−15%，或近20日跌幅≥−10% | 工具效果+1档（封顶S） |
| 中性区 | 回撤−5%~−15% | 无修正 |
| 浅跌区 | 回撤≥−5% | 工具效果−1档（最低C） |

位置修正只作用于B/C级工具（B→A、C→B）；S/A级在深跌区均为S；D级恒为D。

## 5. 综合分级判据

- **S级·强托底**：确立市场底概率高。判据：工具S/A + 深跌区 + 组合拳最后落点。
- **A级·有效托底**：短期止血+中期转正。判据：工具A + 中性/深跌区；或工具S单发。
- **B级·短期脉冲**：脉冲后回落不构成底。判据：工具B/C + 深跌区；或工具A + 浅跌区。
- **C级·无效**：市场不买账。判据：工具B/C + 浅跌/中性区。
- **D级·反作用**：加剧下跌。判据：工具D。

## 6. 组合归因规则

同一组合判定：政策事件间隔≤10交易日且属于同一政策意图（如"稳市场"组合）。
以组合首个事件日为T0评估组合效果；组合内部单条政策单独评估"脉冲贡献"
（T+5），用于判断"第几击起效"：

- 2024-01组合：第一击降准T+5=-1.1%（无效）→ 第二击汇金+3.23%（确立底）
- 2015-07组合：第一击暂停IPO+2.41%（弱）→ 证金2000亿+5.76%（确立底）
- 2026-11组合（进行中）：第一击10-30证监会党委（市场-1.44%未止跌）→ 第二击11-02央行+证监会会议（创业板+3.28%）
