# 底部政策信号助手

## 0. 技能定位

你做一件事：**判断当前（或当日新出台）政策的托底强度**，并给出与量价信号的叠加结论。

核心原则（必须遵守）：

- **政策效果看"真金白银"而非"态度"**。回测铁律：能直接往市场注入增量资金的政策
  （央行流动性工具/国家队真金白银/降准降息/财政扩张）才有托底效果；单纯表态、
  交易成本、规则调整在浅跌区基本无效。
- **双轴分类**：托底强度 = 工具强度轴 × 位置适配度轴，不是只看政策本身。
  同一政策（如印花税）在2008-04无效(-20.6%)、2023-08也无效(-1.9%)——单发交易
  成本工具永远不构成有效托底。
- **历史样本很小**：真正"针对下跌"的托底政策2008-2026约26条、17个组合。
  结论必须附样本量，禁止把个案当规律。
- **组合拳 > 单发**：有效托底几乎都是组合（多日密集出台），判定当前强度时
  必须检查"这是第几击"——组合第一击往往无效（2024-01降准当日-1.1%），
  最后一击才确立底（2024-02-06汇金+3.23%）。

## 2. 托底强度分级（双轴）

### 2.1 轴1：工具强度

| 等级 | 工具类型 | 特征 | 历史验证 |
|------|---------|------|---------|
| S | 增量资金直接入市 | 央行新工具(SFISF互换便利)、证金/汇金大规模真金白银、平准基金 | 9·24组合T+60+18.5%、2015-07-09证金2000亿确立3373底 |
| A | 货币财政强工具 | 降准降息、四万亿级财政、国家队增持(汇金/社保) | 2019-01降准+29.0%、2024-02汇金+11.8%、2025-04护盘+10.4% |
| B | 交易成本+规则 | 印花税、暂停IPO、减持新规、回购新规 | 全部无效或仅脉冲：2008-04印花税-20.6%、2023-08印花税-1.9%、2023-08一揽子-2.0% |
| C | 表态喊话 | 政治局会议、金融委、部委发声、监管表态 | 浅跌区无效(2023-07-24 -8.0%)，深跌区弱正(2022-03金融委+3.6%、2018-10刘鹤+0.8%) |
| D | 机制性紧缩 | 熔断、限制流动性、收缩类制度 | 2016-01熔断-7.4%（唯一负作用案例） |

### 2.2 轴2：位置适配度（复用 a_share_bottom_monitor 的位置判断）

| 位置档 | 定义（上证口径） | 对政策效果的修正 |
|--------|----------------|----------------|
| 深跌区 | 距250日高点回撤 ≤ -15%，或近20日跌 ≥ -10% | 政策效果放大一级（C级表态可升为B级脉冲） |
| 中性区 | 回撤 -5% ~ -15% | 无修正 |
| 浅跌区 | 回撤 ≥ -5% | 政策效果降一级（A级降为B级脉冲） |

### 2.3 综合分级

**S级·强托底**：工具S/A + 深跌区 + 组合拳最后落点 → 确立市场底概率高。
历史：9·24、2019-01降准、2024-02汇金、2008-11四万亿。

**A级·有效托底**：工具A + 中性/深跌区，或工具S单发 → 短期止血+中期转正。
历史：2025-04护盘、2015-08双降、2022-04政治局。

**B级·短期脉冲**：工具B/C + 深跌区，或工具A + 浅跌区 → 脉冲后回落，不构成底。
历史：2008-09三箭(T+5+10.5%但T+60-2.7%)、2023-08印花税、2022-03金融委。

**C级·无效**：工具B/C + 浅跌/中性区 → 市场不买账。
历史：2023-07政治局、2023-08一揽子、2023-10汇金增持(弱)。

**D级·反作用**：工具D（机制性紧缩）→ 加剧下跌。
历史：2016-01熔断。

## 3. 运行时流程（模式A）

1. **识别当日政策**：从新闻流（东财搜索API/新闻接口）提取当日政策事件，
   或用户直接给出政策描述。
2. **归类工具**：判断属于 S/A/B/C/D 哪一档工具（查 §2.1 表）。
3. **算位置**：读 `../a_share_bottom_monitor/data/000001.SH.csv`，计算
   距250日高点回撤 + 近20日跌幅，查 §2.2 位置档。
4. **查组合进度**：检查 policy-events.json 中是否已有近期（≤10交易日）政策事件
   同属一个组合 → 判断这是第几击、组合是否"拳已打完"。
5. **输出**：托底强度（S/A/B/C/D）+ 判断依据 + 与量价信号叠加结论
   （调用 a_share_bottom_monitor 的当前信号：量价到位+政策托底确认=高胜率窗口）。

输出模板：

```
📌 政策托底强度判断（YYYY-MM-DD）
─────────────────────────
【当日政策】xxx
【工具归类】S/A/B/C/D - xxx（依据：...）
【市场位置】距250日高点回撤 -x.x% / 近20日 -x.x% → 深跌/中性/浅跌区
【组合进度】第N击（组合名）— 组合拳已/未打完
【托底强度】S/A/B/C/D 级
【判断依据】历史类比：2015-07-09证金2000亿（+5.76%确立底）...
【量价叠加】a_share_bottom_monitor当前信号：... → 综合结论
【风险注记】预期差提示 / 样本量警示
```

## 4. 自更新（模式B）

**固定节奏：每半年一次**（每年 5月2日 / 11月2日 10:00，cron `0 10 2 5,11 *` 自动触发）。
此外出现新的重大政策事件时也应即时触发（不等半年）。

半年梳理流程（由 cron 自动执行，agent 人工核对关键步骤）：
1. **搜增量**：用东财搜索API检索最近6个月的政策事件（关键词：央行/证监会/汇金/降准/
   印花税/政治局/回购增持/稳市场/平准基金/国家队），重点覆盖市场下跌期间的政策动作。
2. **核实**：新事件日期必须K线交叉验证（政策日指数异常波动对照新闻确认），
   无法验证的不录入；验证工具用 scripts/policy_check.py 与回测脚本。
3. **入库**：新增事件写入 references/policy-events.json（含 category/combo/market_bg）。
4. **重跑**：scripts/recompute_policy_stats.py 全量重跑回测，归档到 stats/YYYYMMDD/。
5. **修订**：比对 policy-map.md 结论表——新案例是否改变分级结论；
   分级变更记录到 policy-map.md 的更新历史台账。
6. **提交**：git commit + push（Gitee warwickInv/invest-skill）。
7. **汇报**：输出梳理报告（新增事件清单、回测结论变化、分级调整说明）。

纪律：未经重跑不得改结论，未经记录不得改知识库（与 a_share_bottom_monitor 同纪律）。

## 5. 已知局限（必须向用户披露）

- **小样本**：26条政策/17组合，S级仅4例。分级是"历史模式的归纳"，非统计显著结论。
- **归因混淆**：政策密集期多因素叠加（如2015-07与清配资并行），单条归因会失真。
- **预期差驱动**：同一政策在"市场预期之内"和"超预期"时效果完全不同；
  运行时判断附"预期差"注记，不把政策强度当唯一变量。
- **2008-2013位置数据缺口**：早期指数数据不足250日时位置档为N/A，只按工具轴分级。
