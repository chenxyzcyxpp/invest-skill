## 指标定义

| 术语 | 口径 |
| --- | --- |
| 回撤（深25/深30） | `close / 过去250个交易日最高收盘价 - 1`；≤−25%为深25档，≤−30%为深30档 |
| 年线 | 过去250个交易日收盘价的简单移动平均 |
| 破年线（浅破/深破） | `close / 250日均线 - 1`；跌破超10%为浅破，超20%为深破，中证2000另测15%档 |
| 连跌 | 当日跌幅<0计1天，任何一天收涨即中断、重新计；连跌≥5日、≥8日为信号档 |
| 单日暴跌 | 当日跌幅>5%（另测>3%档） |
| 恐慌快跌 | 20个交易日前的回撤 − 当前回撤 ≥ 15个百分点 |
| 近20日 | `close / 20个交易日前收盘 - 1` |
| 量比 | 当日成交量 / 过去20日平均成交量 |
| 缩量 | 两个口径：全时段量比<0.7；深跌区量比<0.8（数字不可混比） |
| 放量 | 量比>1.5 |
| 深跌区 | 回撤≤−25%的时期；区域内每个交易日均为一条样本，**不去重** |
| 深跌区缩量/放量 | 深跌区内 + 量比<0.8 / >1.5 |
| RSI | 14日相对强弱指标，简单移动平均口径（ru/rd 均值比，非Wilder平滑） |
| PE滚动分位 | 当日PE-TTM在截至当日的全部历史PE序列中的分位数（expanding） |
| 二次探底 | 信号后20个交易日内，收盘价跌破信号日收盘价3%以上 |

## 统计规则

1. **买卖口径**：买入价 = 触发日收盘价；卖出价 = 第N个交易日收盘价（N=10/20/60）；不含手续费。
2. **事件去重**：v1.1 起所有信号（单因子/深跌区叠加/组合）统一按**窗口不重叠**——相邻触发间隔<60个交易日合并为一次（保留首个），保证任意两个样本的60日收益窗口不重叠。敏感度对照口径「行情起点聚类」见 stats/20261026_dedup_sensitivity/ 底稿（回撤≤-20%区段内每段取首触发，区段外按60天冷却）。
3. **胜率判定**：收益率先四舍五入到1位小数，再判 >0。（复现原流程惯例；
   跳过此步会产生约±3pp的口径差——2018-10-15创业板指一次+0.05%即被舍成0.0%。）
4. **窗口要求**：触发日需满足 `i+60 < n`，保证60日收益可计算。
5. **全时段起点**：第260个交易日起（保证250日滚动指标就绪）。
6. **运气线**：双口径。**step5**（每5个交易日采样，n≈559）为随机买入基准，**判定信号有效/反向以它为界**；**step60**（每60个交易日采样，窗口不重叠、与信号同口径，n=47）仅作展示参考——n=47 存在相位偏差（深证/创业板明显偏低），**不得作为判定基准**。判定阈值：胜率高于 step5+5pp 为有效，低于 step5−5pp 为反向。

## 已知数据局限（每次输出涉及时必须附带）

1. 中证2000（932000.CSI）：2023-08正式发布；2013-2022为回溯序列
   （按当时市值排名1801-3800名模拟加权）；无交易所PE数据；2023年前无对应ETF。
2. 深证成指PE序列自2020-10起，估值类信号有效样本期约4年，短于其他指数。
3. 小样本信号（触发<10次）一律标注"小样本，仅供参考"，不得作为主信号推荐。

## 路径统计口径（v1.2 决策层新增）

> **本节新增不改变 v1.0 胜率与信号有效性口径，结论仍可比。** 本节只定义
> 「信号触发之后怎么走」的路径描述量，不参与 `signal_map.json` 的有效/无效判定；
> 上文「统计规则」1~6 条、事件去重口径、运气线判定基准一律不变。路径分布独立
> 存放于 `references/path_map.json`，由 `scripts/path_stats.py` 从 `data/` 逐笔计算。

| 术语 | 定义 |
| --- | --- |
| MAE（最大浮亏） | 触发日收盘买入后、持有期内（**不含买入当日**）最低收盘价 / 买入价 − 1，单位 %。若买入后全程上涨，该值为正（本轮无浮亏）；`mae_worst` 为全部样本的最小值。 |
| breakeven_day（回本天数） | 买入后首次收盘价 > 买入价的交易日序号；持有期内未回本记 `None`。`breakeven_rate` 为回本样本占比。 |
| under3_20d（二次探底） | 买入后前 `HOLD_DAYS[1]` 个交易日内，出现收盘价 < 买入价 ×(1+`SECOND_LEG`)。沿用上文「二次探底」口径。 |
| MAE 分位数 | 全部样本 MAE 的百分位数，分位点由 `decision-rules.md` 的 `mae_quantiles` 定义；`mae_worst` 为样本最小值。 |
| deep_random_baseline（深跌区随机买入基准） | 在 `dd < DEEP25` 的深跌区内、按 `deep_baseline_sample_step` 采样步长取点且要求完整持有窗口，用同一 `win_rate` 口径计算的后 60 日胜率、中位收益与中位 MAE。与全时段 step5 / step60 运气线并列为第二基准。 |
| Wilson 区间 | 胜率的 Wilson score 95% 双侧置信区间，`z` 由 `decision-rules.md` 的 `wilson_z` 定义；小样本必须连同区间一起报，禁止只报胜率。 |
| 年化波动 | `std(diff(log(close))) × sqrt(annual_trading_days) × 100`，窗口取 `HOLD_DAYS` 末档；年化因子由 `decision-rules.md` 定义。 |
| 双基准超额 | `excess_vs_baseline_pp = win60 − signal_map.baseline[code]`；`excess_vs_deep_pp = win60 − deep_random_baseline.win60`。两个值必须由代码相减得出，不得写成常量。 |

事件去重复用 `core.dedup` + `core.GAP_SINGLE`，持有期取 `core.HOLD_DAYS` 末档，
收益判定沿用 `core.win_rate`（先四舍五入到 1 位小数再判 >0）。
阈值类参数（Wilson z、年化交易日、MAE 分位点、深跌区采样步长、尾部分位）
**只**在 `references/decision-rules.md` 的 `MACHINE_CONFIG` 定义一次并由脚本读取。

**路径统计是历史样本分布，不是确定性承诺**；历史回测 ≠ 未来收益，不构成投资建议。
