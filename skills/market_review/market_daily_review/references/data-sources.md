# 数据采集与可降级方案（Data Sources & Degradation）

> 本文件定义 `market_daily_review`（股市每日收评）的**数据采集层降级策略**，沿用 racing-quant-ai 的
> 「四级降级链路 + 数据校验铁律」设计，并适配 invest-skill 体系的开源网关惯例。SKILL.md 第六节为
> 精简版，本文为完整实现细则。**本 Skill 不依赖任何商业数据供应商，全部使用开源数据源。**

---

## 一、🔴 数据校验铁律（最高优先级）

1. 所有指数 / 板块 / 个股 / 资金流 / 技术面数据，**必须来自实际数据源的调用结果**。
2. 核心行情（指数 / 板块）四类数据源**全部失败**时，脚本抛 `MKT_REVIEW_001` 退出，**绝不输出伪造报告**。
3. 龙虎榜在开源体系中覆盖较弱（Tushare/Akshare 可部分覆盖）；**公开资讯（市场级新闻）离线源均无接口**，缺口按「数据待补充」标注，并提示可用 `--news-file` 由 agent 经 WebSearch 注入——**严禁编造任何具体数值**
   （涨跌幅、成交额、净流入、PE/PB、换手率、新闻标题等）。违反视为重大事故。
4. 若全部分级源对某维度都失败，**逐维度标注缺失**，绝不用估算值、猜测值或模型生成值替代。
5. 报告中每个数值须可溯源至具体数据源（通过 `data_source` 字段 + 第十节 `degrade_trace`）。

---

## 二、四级降级链路（数据源优先级）

```
L1  Tushare（优先，需 TUSHARE_TOKEN）      ← 指数/涨跌统计/板块/个股/资金流/技术面
        │ 未配置 token / 连接失败 / 权限不足
        ▼
L2  Akshare（开源主源）                     ← 指数(sina/em)/涨跌统计/板块/个股/资金流/龙虎榜/技术面
        │ akshare 不可用 / 受限网络拦截 EastMoney
        ▼
L3  腾讯财经 / 东方财富 Push API（网页兜底）← 仅指数实时行情字段
        │ 仍不可用 / 返回空
        ▼
L4  演示数据（--demo）                       ← 仅管线校验，不参与生产
```

### L1 — Tushare（优先源）
- 配置 `TUSHARE_TOKEN` 后可用，覆盖指数 / 涨跌统计 / 板块 / 个股 / 资金流 / 技术面。
- 部分高级接口需更高积分权限，权限不足时按维度降级到 L2。
- **降级触发**：未配置 token / 连接失败 / 权限不足 / 返回空。

### L2 — Akshare（开源主源）
- 覆盖：指数（sina/em）、涨跌统计（全市场快照聚合）、板块（同花顺行业汇总）、个股异动（全市场快照排序）、
  资金流（市场 + 行业）、龙虎榜（em/sina）、技术面（指数日线计算 RSI/MA）。
- **受限网络**：EastMoney 接口（`stock_zh_a_spot_em` 等）可能返回空，脚本内已做 em→sina 回退。
- **降级触发**：akshare 未安装 / 全部后端不可达。

### L3 — 腾讯财经 / 东方财富 Push API（网页兜底）
- 当 L1 / L2 都不可用时，**仅用于指数实时行情字段兜底**。
- 腾讯财经：`https://qt.gtimg.cn/q=sh000001,...`（解析 `v_` 行情串）。
- 东方财富：`https://push2.eastmoney.com/api/qt/stock/get?secid={市场前缀}.{代码}&fields=f43,f57,f58,f170`
  - 字段映射：`f43`=最新价, `f57`=代码, `f58`=名称, `f170`=涨跌幅。
  - 指数 secid：上证 `1.000001`、深证 `0.399001`、创业板 `0.399006`、沪深300 `1.000300`、科创50 `1.000688`、上证50 `1.000016`、恒生 `100.HSI`、恒生科技 `105.HSTECH`。
  - 沪市前缀 `1.`、深市 `0.`。
- ⚠️ 仅在可访问公开网页环境下生效；板块 / 个股 / 资金流 / 龙虎榜 / 新闻无网页兜底，缺失即标注。

### L4 — 演示数据（--demo）
- 内置样例，仅用于验证管线与离线预览，**不参与真实生产**（`data_source=demo` 明确标记）。

## 三、接口可靠性要点（实测经验）

| 数据源 / 接口 | 可靠性 | 说明 |
|---|---|---|
| L2 Akshare `stock_board_industry_summary_ths` | ✅ 稳定 | 同花顺行业板块汇总（约 90 个），含涨跌幅 / 成交额 / 净流入 |
| L2 Akshare `stock_zh_index_spot_sina` | ✅ 稳定 | A 股指数现货（上证 / 深证 / 创业板 / 沪深300 / 科创50 / 上证50） |
| L2 Akshare `stock_zh_a_spot_em` | ❌ 受限网络高频返空 | 脚本自动回退 `stock_zh_a_spot`（sina 现货） |
| L2 Akshare `stock_market_fund_flow` | ✅ 可用 | 全市场主力净流入 |
| L2 Akshare `stock_lhb_detail_em` | ⚠️ 受限网络可能失败 | 回退 `stock_lhb_detail_daily_sina` |
| L2 Akshare `index_zh_a_hist` | ✅ 稳定 | 指数日线，用于技术面 RSI/MA 计算 |
| L1 Tushare `index_daily` / `moneyflow` | ✅ 需 token + 积分 | 高级权限接口权限不足时降级 |
| L3 东方财富 Push API | ⚠️ 环境依赖 | 部分沙箱 `curl` 返回空，需网页可访问 |

## 四、日期格式差异（必处理，否则静默返空）

| 数据源 | 日期格式 | 示例 |
|---|---|---|
| L2 Akshare `index_zh_a_hist` / `stock_market_fund_flow` | `YYYYMMDD` | 20261022 |
| L1 Tushare | `YYYYMMDD` | 20261022 |
| 脚本内部 / 用户输入 | `YYYY-MM-DD` | 2026-10-22 |

> 调用前按目标源格式转换；历史日期查询务必确认所用接口支持指定日期。

---

## 五、交叉验证

- 从 L1 取得数据后，与 L2 对**关键字段**（指数涨跌幅、成交额）做一致性比对。
- 偏差过大时以 L1 为准，并在报告中标注「数据交叉校验存在偏差」。
- 板块 / 个股 / 资金流等 L2 覆盖较弱的维度，不做强制交叉验证，缺失即标注。

---

## 六、采集状态报告（每次取数后记录）

- 内部记录各维度**成功 / 失败计数**的采集状态摘要（`degrade_trace` 列表）。
- 失败维度在报告第十节**明确标注**「数据待补充 / 数据获取失败」，不隐藏、不跳过。

---

## 七、Prompt 硬护栏（写入取数 / 撰写提示词）

1. 行情 / 财务 / 资金数据**只能来自实际调用结果**。
2. 若某维度为 `N/A` 或获取失败，**必须如实标注**，严禁编造任何具体数字。
3. 禁止用估算值、猜测值、模型生成值替代真实数据。
4. 每个数值标注来源（`data_source`）与降级标记（`degrade_trace`）。
5. 末尾附完整免责声明（见 SKILL.md / output-template.md）。
