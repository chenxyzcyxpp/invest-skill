# 查询示例

## 示例 1：基础复盘

**用户请求**：生成隔夜外围市场复盘报告

**处理流程**：
1. 确认复盘日期为 2026-04-28（前一交易日）
2. 并行调用东方财富妙想、腾讯自选股、通达信等接口获取行情、宏观与资讯锚点
3. 按 v1.4.3 结构生成报告：全球行情速览 → 今日五件事 → 一张图看隔夜 → 主线与分歧 → 决策时间线（常驻）→ 数据口径、来源与限制
4. 输出 Markdown + 自包含 HTML 到 `files/report/`，并执行溯源编号规范化与自包含校验

## 示例 2：重点关注科技股

**用户请求**：外围市场复盘，重点关注科技股

**处理流程**：
1. 在美股章节重点分析苹果、英伟达、微软、谷歌等
2. 在港股章节重点分析腾讯、阿里、美团等科技股
3. 在「今日五件事」与「主线与分歧」中重点分析科技板块映射

## 示例 3：指定日期复盘

**用户请求**：生成 2026-04-25 的全球市场复盘

**处理流程**：
1. 使用用户指定的日期 2026-04-25
2. 获取该交易日的美股、港股数据
3. 获取该日前后 24 小时的宏观舆情
4. 生成报告并标注数据截止日期
