# 数据、事件、因果、去重与交付终检

## 一、数据有效性

1. 检查空表、错误、超时和无返回体；未实际查询不得写“暂无数据”。
2. 实体、代码、市场必须匹配，避免指数与公司、同名证券混淆。
3. 交易日、盘中/收盘、财务报告期、单位、币种、复权和指标口径必须明确。
4. 多标的比较必须同时点、同口径；不一致则分组展示，不得直接排序。
5. 精确行情、财务、估值、宏观数值优先结构化工具；文本数值不得替代可获得的结构化值。

缺失数据写法：

```markdown
**【数据说明】** [数据类型] 暂缺，原因：[原因]。对结论的影响：[影响]。
```

## 二、日期、时区与事件

- 目标复盘日与生成时点的时区、休市、夏令时必须核对；周一白天默认取美股上周五收盘。
- 无法确认精确时间的事件写“具体时间待确认”，不得凭惯例推断或编造。
- 事件前瞻模块开启时，高敏感事件卡逐项检查：发布机构、当地日期时间、当地时区与夏令时、北京时间换算、前值/预期/修正值口径、事件状态（已确认/高概率/市场预期）、敏感资产、关键阈值、A股传导、偏强/符合预期/偏弱情景切换指标。
- 未来一周大事预览只列已确认/高概率/市场预期事项，未经确认不进主表；覆盖未来约 7 个自然日，普通事件进表、高敏感事件另立事件卡。

## 三、事实、观点与推演

- **事实**：结构化数据、公告、可核验事件。
- **机构观点**：注明机构、日期、适用市场和时间尺度。
- **本报告分析**：写出前提、机制、置信度和失效条件。

单一机构不得称为共识；同时发生不得自动写成因果。跨资产信号冲突时降低置信度。

证据强度分三档：**强**（结构化数据、公告或可直接核验的一手披露）、**中**（多个独立机构观点一致且机制合理）、**弱**（主题关联或历史类比，只列观察线索）。催化剂标注：已确认、高概率窗口、市场预期、未经确认。影响期限分三档：当日、1—5个交易日、一个季度以上。

## 四、A股映射与主线分级

每条映射检查：

1. 业务、订单、价格、成本、盈利或估值传导是否成立；
2. 作用期限是否明确；
3. 当前定价是否有依据；
4. 是否有盘中/后续验证指标；
5. 是否有反向信号和失效条件。

| 等级 | 定义 | 输出要求 |
|---|---|---|
| A | 至少满足两项：新增事实、明显价格反应、直接映射、当日敏感 | 完整分析卡，150—250字 |
| B | 机制成立但证据或映射较弱 | 进入速览表 |
| C | 主要为主题或情绪关联 | 仅列观察，不进高置信度结论 |

重点公司只承担主线验证，不重复赛道分析或完整财务点评。

## 五、因果链与图表一致性

1. 三段式图固定为“重大隔夜事件 → 核心定价变量 → 中国市场主线”。
2. 第一段事件门槛：必须可能显著改变全球利率、通胀、风险偏好、汇率、商品或产业定价；普通公司公告、个股财报、合同、募资和影响范围有限的公司事件一律排除。
3. 第一段每框最多三行：“事件短标题（≤18字）+1组关键数据（1—2个数值）+一句市场含义（≤20字）”。关键数据必须来自本轮有效来源，优先政策概率、宏观指标、利率汇率、指数或商品涨跌；不得堆叠超过2个数值，不得塞入公司明细或长句。
4. 第一段到第二段必须严格一对一：每项重大事件只连接一个首要定价变量，次要影响写入正文，不增加交叉连线。
5. 第二段到第三段按真实机制建立多对多关系；同一变量可影响多个主线，同一主线可由多个变量共同驱动。
6. 第二段每个节点最多连接3条第三段主线；每条边须能解释机制，交叉线采用曲线和较低透明度，避免压住节点文字。
7. 区分直接触发、外围助推和背景因素；非直接因素不得写成主因。
8. 每个节点在正文有事实或分析对应；图中不放具体公司，不出现正文未验证的事件或板块。
9. 图后只写一段总解释，不逐节点重复。
10. HTML 交付时传导图必须保留完整节点级连线：用内联 SVG 绘制（A→B 一对一水平线、B→C 多对多曲线，均带箭头 marker），禁止用纯 HTML flexbox 三列加大箭头简化而丢失节点间连线。
11. 文字与背景对比度强制：深色底（第三段“中国市场主线”节点）用白色加粗文字，浅色底（第一/第二段）配深色文字；白底→深字、蓝底→白字，不得出现同色系互遮。
12. 图表数量约束：只有A级主线存在至少三层明确产业传导时，才可增加1张局部产业链图；全文原则上最多3张分析图（不包括基础行情图）。

## 六、内容深度与去重

### 必须保留

- 因果机制；
- 跨资产确认或冲突；
- 当前定价与预期差；
- 盘中/后续验证；
- 反方信号与失效条件。

### 必须去重

1. 同一行情事实只完整陈述一次；后文只引用，不重复数值和背景。全球行情速览（第一章）承载全部原始数据，后续章节只引用不重述。
2. 决策层「今日五件事」必须固定 5 件，且每件四要素齐全（事实 + 角标、含义且标注“本报告观点”、A股传导、验证/失效条件）；排序遵循优先级（利率/通胀总开关 > 全球产业定价 > 地缘/商品 > 国内重大政策 > 其他）。图表支撑放“一张图看隔夜”（双图 + 三段式传导图）。主线总表只承载市场级/行业级事实与分级、验证、定价、失效条件；重点公司验证模块默认关闭、不进入决策层与主线总表。
3. 主线与分歧章节按新框架撰写：主线固定回答三问——「在交易什么叙事 / 交易到什么位置（定价·拥挤·阶段）/ 历史类似交易后续走势（可比参照，非预测）」，以“速览表 + 逐条展开（≤3 条）”呈现；分歧固定回答两问——「博弈最剧烈环节（战场）/ 认知差（已知真相 vs 已定价）/ 情绪差（情绪 vs 基本面）/ 冲突点（认知与情绪背离、谁先收敛）」，同样“速览表 + 逐条展开（≤3 条）”。逐行扫描并排除单家公司名称、证券代码、公司公告、订单/合同、募资、回购、调研纪要、个股估值和个股涨跌；公司事件只有去公司化后仍足以改变行业或全球供应链定价，才可作为行业事实保留。历史可比必须显式标注“非预测/参照”。
4. 主线与分歧必须与「今日五件事」「一张图」论证一脉相承，不得另起炉灶；每条主线的“交易到哪了”给出明确的阶段判断（早期/共识/过度定价/出清）与关键价位或阈值；**每条主线末尾必须给「对A股潜在影响」，章节末尾必须给「主线对A股的综合影响」小结**。不得把行情背景重述当研判。
5. 分歧的“认知差”须落在“已知真相 vs 已定价”的落差上（哪些真信号尚未被充分定价），“情绪差”须落在“市场情绪/行为 vs 基本面现实”的落差上；冲突点须给出收敛路径与触发条件，并判断当前偏认知侧还是情绪侧，不得写成单纯的看多/看空罗列。**每条分歧末尾必须给「对A股潜在影响」，章节末尾必须给「分歧对A股的潜在影响与应对」小结**。
6. 重点公司验证模块若启用，单列3—5家代表公司，字段须含公开事实日期、收盘验证、估值口径、下一观察点和风险信号；公司信息不得回流今日五件事或主线总表。
7. 每条主线必须在“级别/驱动”列标注影响期限，不新增单列。期限仅用三档：短期冲击（当日—5日）、阶段催化（1季度内）、长期叙事（1季度以上）；可多选，但长期叙事必须有产业、盈利、供需或政策持续性证据，否则标“长期叙事待证”。
8. 主线总表“新增事实与机制”列逐项检查时间：精确时刻写“YYYY-MM-DD HH:mm（北京时间）”；只返回日期写“YYYY-MM-DD（具体时刻未披露）”；行情状态写“截至YYYY-MM-DD HH:mm”；无法确认写“具体发布时间未取得”。不得把查询时间、文章抓取时间或模型推断时间写成事件发生时间。
9. 三段式图只展示路径，不复制正文段落。
10. 全球行情速览（第一章）只提供详细行情证据，不再次完成A股映射；A股映射只在今日五件事与主线总表中出现。

### 段落检查

每段最多5句，依次承担：结论、事实、机制、验证、反方。首句必须加粗给出判断；不要求写满，但不得以第6句继续重复背景。

## 七、风格与市场宽度

1. 一张图看隔夜默认两张图并排同一行：左图=全球主要资产涨跌对比图（统一红涨绿跌），右图=A股盘中验证柱形图（用 `subplots(2,1)` 上下两个**独立子图**：上图“指数/板块”、下图“个股”，两段各自按涨幅降序、均红涨绿跌、个股与指数不混排）；不设A股验证表格，不叠加重复指标表。
2. 全球主要资产涨跌图排序固定：主要海外股指在前（美股→亚太→欧洲），商品与跨资产（原油/黄金/白银/美元/VIX等）在后。
3. 两图统一高度、坐标、图例和视觉尺度，配色全篇统一红涨绿跌。
4. 每张图必须划分标签区、绘图区和数值区：标签文字包围盒与任一柱形不得重叠，标签区与柱形区至少留24px；长负值柱应右移零轴或降低比例。
5. 输出前必须渲染SVG并做碰撞检查：原始尺寸、768px和375px下检查文字可读性；可用DOM `getBBox()` 比较文本与非所属柱形，或用截图人工确认。发现交叠、裁切、遮挡即重排，禁止仅凭SVG源码通过。
6. 图后只保留一句结构判定，不逐项复述数字。
7. 数据不足时使用一张紧凑对比表并说明缺口，不得用主观印象替代宽度指标。
8. A股验证柱形图采用上下两个独立子图：`fig, axes = plt.subplots(2,1, gridspec_kw={"height_ratios":[5,7], "hspace":0.32})`，上图“指数/板块”（y 轴标签蓝色 #1D4ED8）、下图“个股”（y 轴标签紫色 #7C3AED）；各子图标题用 `ax.set_title(..., loc="left", color=对应色)` 置于子图左上角，上半子图 `tick_params(axis="x", labelbottom=False)` 隐藏 x 刻度标签、底部子图显示，整图 `fig.suptitle` 标注标题与百分比单位。两段各自按涨幅降序，个股与指数不混排。
9. 图表尺寸受控：全球资产涨跌图与A股验证柱形图 figsize 宽均不超过 8 英寸、dpi 120，且**两张图 figsize 宽高尺寸必须严格一致**（推荐均 8.2×8.6、dpi 120，输出分辨率一致），否则并排时高度不同导致横坐标轴（x 轴）底部错位；图例/分段标签禁止用 `bbox_to_anchor` 的 x 坐标超出 1.0（外置），否则 `bbox_inches="tight"` 会撑宽单张图、破坏两张图并排对齐；HTML 中两图并排同一行（flex 双列，各 max-width ≤ 49%）、三段式传导图 ≤ 90%，任何图表不得以 100% 宽度渲染。**坐标轴必须对齐**：两张图用相同 x 轴范围与刻度（统一 `set_xlim`/`set_xticks`，如 `xlim=(-2.5,7.5)`、`xticks=[-2,0,2,4,6]`），并用固定 `subplots_adjust(left=0.22, right=0.98, bottom=0.06, top=0.93)` 代替 `bbox_inches="tight"` 自动裁剪——**`savefig` 必须去掉 `bbox_inches="tight"` 参数**，否则会按各自 y 轴标签长度重新裁边、导致两图绘图区宽度不一而 x 轴错位；两图 `left`/`right`/`bottom` 完全一致，保证零点线、百分比刻度与 x=0 参考线在两张图里水平位置一致且 x 轴落在同一垂直线，不受 y 轴标签长度或单/双子图结构差异影响。
10. 分组信息（美股/港股/亚太/跨资产等）禁止用 ax.text 叠加在坐标轴上，改用 y 轴刻度标签着色 + 图例区分。图例置于**绘图区内右上角顶部留白带**（`loc="upper right"` + `bbox_to_anchor=(1.0, 1.0)`、`ncol=4` 横向排布，配合 `set_ylim` 顶部留白 `top_pad≈1.9`），带白色底框（`frameon=True`、`framealpha=1`）；禁止 `bbox_to_anchor` 的 x 超出 1.0 外置（会撑宽图、破坏并排对齐），也禁止 `loc="lower right"` 置入绘图区与柱体/数值标签重叠。分组配色必须高区分度（推荐蓝 `#1D4ED8`/翠绿 `#059669`/紫 `#7C3AED`/橙 `#D97706`），禁止用相近色系（如深蓝 `#1f3a8a` 与青蓝 `#0e7490`），且必须与"红涨绿跌"的柱体颜色严格区分（分组色不得用红/绿）。
11. 数值标签统一放在柱体末端外侧（正值柱右侧、负值柱左侧），禁止放入柱内；生成后用 set_xlim(vmin - span*0.22, vmax + span*0.22) 动态留足边距，确保标签与柱体、坐标轴边界零重叠、零裁剪；存在极端值时短柱标签仍放柱外，负值柱较长时优先右移零轴并压缩比例。
12. y 轴类别标签（指数名/个股名）必须用 set_yticks + set_yticklabels 放置在图外左侧，禁止用 ax.text 置于绘图区内（如 x=-0.28 等固定坐标）导致与负值柱重叠。

## 八、跨资产表

删除“数据性质”列。字段统一为：资产信号、最新变化、交易含义/A股传导、期限、验证指标、失效条件。来源性质放脚注或第五章。

## 九、三级溯源

1. 正文数值、事件和机构观点使用数字角标 `[N]`。
2. 每个小节末尾放来源块，注明数据截止或发布日期。
3. 第五章按首次出现顺序归集来源并去重。
4. 底层 `<a class="chat_link_a" data-refId="...">` 与 `data-refId` 必须原样保留；显示层按首次出现顺序映射为连续数字。同一 `data-refId` 在正文和附录必须复用同一编号。
5. 映射必须幂等：连续执行两次转换后编号完全一致，不得因样式表或既有映射中的数字导致序号递增。
6. HTML终检提取所有 `.chat_link_a` 的可见文本，须全部匹配正则 `^\[\d+\]$`；出现 `[know]`、`[aslq]`、`[news]` 等字母脚标即判失败并重生成。
7. 溯源标签必须存在：HTML 中 `.chat_link_a` 数量须 > 0（不得为 0）；正文与来源附录不得残留 `[N]` 等未替换的占位符；数据来源表必须有“脚标”列（脚标/类型/来源摘要/截止时间），且脚标与正文引用编号一致。

文本值与结构化值冲突时，优先结构化值；无法核验的文本数值不得作为事实锚点。

## 十、版式与交付终检

- [ ] Markdown与HTML均已创建且内容一致；
- [ ] 无目录、无单独封面；
- [ ] 一级标题（报告题目）必须用标准 markdown `# ` 语法，禁止用 `<div align="center">` 等 HTML 块包裹标题——HTML 块内的 `#` 不会被解析，会导致标题未加粗、井号残留；需居中时用 `<h1 style="text-align:center">` 而非包裹 div；
- [ ] 章节顺序为：全球行情速览 → 今日五件事（决策层）→ 一张图看隔夜 → 主线与分歧 → 决策时间线（常驻）→ 数据口径、来源与限制；**「六、决策时间线」为常驻章节**（取代原默认关闭的事件前瞻），含未来24小时关键节点条（始终显示）+ 未来一周大事预览（`<details>` 可折叠）+ 高敏感事件卡 + 情景切换矩阵，且所有情景标记为推演、不得写成既成事实；
