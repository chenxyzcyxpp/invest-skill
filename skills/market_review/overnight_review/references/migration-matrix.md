## 新增或强化

1. 核心第二章合并驱动、跨资产验证、A股映射、主线、机构分歧和重点公司。
2. 高敏感事件必须包含发布机构、时区、夏令时、北京时间、前值、预期、修正值和验证阈值。
3. 第一章风格与宽度由文字解释改为“全球主要资产涨跌图 + A股盘中验证柱形图”并排。
4. A/B/C主线分级与差异化篇幅。
5. 每段最多5句的结论—事实—机制—验证—反方结构。
6. 同一事实只完整陈述一次，第四章仅作证据层。
7. HTML/PDF宽表必须换行并通过关键词列、末列和图表比例终检。

## 删除项

v1.2.0 阶段无业务覆盖删除，删除的是重复陈述、“数据性质”正文列和无结论的背景堆砌。

**后续版本追加删除（v1.4.0 / v1.4.1）**：「今日时钟」整章（事件卡 + 72 小时日历，与五件事重复）、固定免责声明（模板、硬红线、终检与输出均已移除）、“证据层”章节标注。当前结构为：全球行情速览 → 今日五件事 → 一张图看隔夜 → 主线与分歧 → 决策时间线（常驻）→ 数据口径、来源与限制。

**v1.4.2 追加（事件前瞻作为可选模块补回）**：原 v1.4.0/1.4.1 删除的「今日时钟」并非彻底移除业务能力，而是默认关闭。本版将事件前瞻重新作为**可选模块**补回：当用户显式要求“事件日历 / 下周关注 / 前瞻”或需规划未来交易窗口时，在「主线与分歧」之后可选生成「六、事件前瞻」，含 6.1 高敏感事件卡、6.2 未来一周大事预览（由“未来72小时事件日历”扩展为覆盖约 7 个自然日）、6.3 情景切换矩阵；所有情景标记为推演。默认不生成，避免与「今日五件事」结论层重复。同时修正 v1.4.1 包内 `.market/origin.json` 的 `installedVersion` 仍滞留 1.2.0 的瑕疵，升为 1.4.2。

**v1.4.3 追加（事件前瞻升级为常驻决策时间线 + 主线/分歧框架重构）**：
- 把 v1.4.2「默认关闭的事件前瞻」升级为**常驻决策时间线**「六、决策时间线（常驻）」——为报告提供“时间锚”，回答“接下来盯什么、何时验证”；含 6.1 未来24小时关键节点条（始终显示，≤5 个）、6.2 未来一周大事预览（用 `<details>` 原生折叠、覆盖约 7 个自然日，由“未来72小时事件日历”进一步扩窗）、6.3 高敏感事件卡、6.4 情景切换矩阵；所有情景标记为推演。既补回 v1.2.0 最被认可的时间锚（v1.4.1 直接删除），又用可折叠交互避免 v1.2.0 的冗长。
- 重构「主线与分歧」框架：主线固定回答三问——在交易什么叙事 / 交易到什么位置（定价·拥挤·阶段）/ 历史类似交易后续走势（可比参照，非预测）；分歧固定回答两问——博弈最剧烈环节（战场）/ 认知差（已知真相 vs 已定价）/ 情绪差（情绪 vs 基本面）/ 冲突点（认知与情绪背离、谁先收敛）。两节均以“速览表 + 逐条展开（≤3 条）”呈现，**每条主线/分歧末尾必须给「对A股潜在影响」，章节末尾必须给综合小结**，强化 A股 实操价值。
- 模板占位符同步更名：第五章 `CORE_DRIVER_TABLE`/`DIVERGENCE_TABLE` → `MAIN_THREAD_SECTION`/`DIVERGENCE_SECTION`；第六章 `EVENT_PREVIEW_SECTION`（原 `display:none` 可选容器）改为常驻 `DECISION_TIMELINE_SECTION`；三段式传导图容器 `mermaid-frame` 改名 `chart-block`（规避预览管线对 mermaid 容器的误处理）。
- 修正并统一 `.market/origin.json` 的 `installedVersion` 为 1.4.3。
