# 隔夜外围市场复盘

以 Bloomberg “Five Things” 骨架为决策层——**今日五件事**（按优先级排序、每件事固定“事实 → 含义（本报告观点）→ A股传导 → 验证/失效”四句式）。新版逻辑（v1.4.0）采用**先证据、后结论**：先给「全球行情速览」（原始数据），再进入「今日五件事」（决策层分析），其后接图表支撑与主线分歧，避免与原“今日时钟”章节重复。事件前瞻升级为**常驻决策时间线**——常驻锚定未来24h关键节点 + 可折叠未来一周大事预览（由“未来72小时事件日历”扩展而来）+ 高敏感事件卡 + 情景切换矩阵，为报告提供“时间锚”；所有情景标记为推演。

## 核心原则

1. **A股实操价值优先**：核心决策层必须回答“为什么、映射什么、如何验证、何时失效”。
2. **事实先于观点**：所有推演以结构化行情、公告、宏观数据或可核验事件为锚点；机构观点仅用于校准共识、拥挤度和预期差。
3. **分析不等于重复**：保留因果机制、跨资产确认、当前定价、反方信号和失效条件；一条主线只完整分析一次。
4. **图表与文字互补**：图表回答“发生了什么”，文字回答“为什么、能否持续、如何验证”。
5. 不提供买卖、仓位、止损建议；重点个股统一称“重点公司验证”。

## 默认参数

- 复盘日期：最近一个已完成的海外交易日；用户指定时从其指定。
- 数据窗口：行情取对应市场最近收盘；新闻/观点原则上近24小时。
- 正文结构：全球行情速览 → 今日五件事（决策层）→ 一张图看隔夜（图表支撑）→ 主线与分歧 → 决策时间线（常驻）→ 口径与来源。
- 篇幅：正文约2500—3500字，2—3分钟读完；不机械删减核心分析，减少的是重复行情描述和无结论背景。
- 今日五件事固定 5 件，按优先级（利率/通胀总开关 > 全球产业定价 > 地缘/商品 > 国内重大政策 > 其他）排序；A级主线2条、机构分歧不超过3条；重点公司验证模块默认关闭。
- 决策时间线（原事件前瞻）默认常驻输出：含未来24h关键节点条（始终显示）与可折叠未来一周大事预览（覆盖约 7 个自然日，由“未来72小时事件日历”扩展而来）、高敏感事件卡、情景切换矩阵；所有情景标记为推演。
- 输出：`files/report/隔夜外围市场复盘_定制版_{YYYYMMDD}.md` 与同名 `.html`；HTML必须可脱离workspace单独发送和离线打开。

## 强制执行流程

### Step 1：日期、时区与证据锚点对齐

确定北京时间生成时点与目标复盘日；分别核对美国、香港、日本、韩国、欧洲市场对应交易日及周末/休市/夏令时状态（周一白天默认取美股上周五收盘，休市继续回溯）。根据生成时点切换盘前/盘中/盘后措辞；记录关键事件发布机构、当地时间与时区、北京时间、确认状态与来源（无法确认写“具体时间待确认”，不得凭惯例推断或编造）。

### Step 2：获取事实锚点

并行获取并校验：全球主要指数与风格/宽度、港股与中概、日韩欧洲新兴市场、跨资产（美债/美元/VIX/油金铜铝）、事件（宏观/央行/政策/地缘/公司）、A股验证锚点。精确数值优先结构化工具，事件优先资讯/公告，观点优先正式研报及晨会。接口与回退规则见 `references/data-sources.md`。

### Step 3：构建「全球行情速览」证据层

先铺陈原始数据：美国、欧洲、港股与中概、亚太及新兴市场、股债汇商品五小节，全部用表格与简短“异常点分析”承载，**只陈列事实、不在此展开 A股映射与结论**。这是后续五件事的事实底座。

### Step 4：构建「今日五件事」决策层

提炼 **5 件** 按优先级排序的事件（利率/通胀总开关 > 全球产业定价 > 地缘/商品 > 国内重大政策 > 其他），每件固定四句式：事实（带溯源角标）→ 含义（明确标注“本报告观点”）→ A股传导 → 验证/失效。结尾给一行“今日市场状态”总判定。这是报告唯一的结论前置层。

### Step 5：构建图表支撑与主线分歧

生成全球主要资产涨跌对比图 + A股盘中验证柱形图（上下两个子图，左右 x 轴对齐）两张并排；紧随其后放三段式传导图（内联 SVG）。再统一收敛为「主线与分歧」：主线固定三问（在交易什么 / 交易到哪了·定价拥挤阶段 / 历史类似交易后续走势·非预测），以速览表 + 逐条展开（≤3 条）呈现，每条末尾给「对A股潜在影响」、章节末尾给综合小结；分歧固定两问（博弈战场 / 认知差·情绪差·冲突点），同样速览表 + 逐条展开（≤3 条）并给 A股影响与应对小结；重点公司验证模块默认关闭。字段与规则见 `references/report-template.md`。

### Step 6：决策时间线（常驻）

「主线与分歧」之后常驻生成「六、决策时间线」——未来24小时关键节点条（始终显示，≤5 个）+ 未来一周大事预览（`<details>` 可折叠，覆盖约 7 个自然日，由“未来72小时事件日历”扩展而来）+ 高敏感事件卡 + 情景切换矩阵。所有情景标记为**推演**，不得写成既成事实；普通事件进预览表，高敏感事件另立事件卡。字段与规则见 `references/report-template.md` 的「六、决策时间线（常驻）」。

### Step 7：生成、去重与交付

严格按 `references/report-template.md` 生成 Markdown；调用HTML产出能力生成同内容HTML（版式遵循 `references/report-template.html`），HTML须自包含（图表内嵌 data URI，无本地路径依赖），执行 `scripts/render_self_contained_html.py`。执行 `references/data-validation.md` 的数据、因果、去重和版式终检。两文件写入 `files/report/` 并标记交付物。生成后执行 `scripts/normalize_traceability.py` 规范化溯源编号。

## 硬红线（不可省略）

- **五件事纪律**：「今日五件事」固定 5 件，每件必须含四要素——事实（含角标）、含义（明确标注“本报告观点”）、A股传导、验证/失效条件；禁止出现无 A股传导或无可证伪条件的“裸事件”。排序须遵循优先级，严禁把普通公司公告塞入决策层。
- **红涨绿跌全篇统一**；A股盘中验证柱形图分“指数/板块段”（上）与“个股段”（下）上下两段，各段独立按涨幅降序，个股与指数不混排，分段标签以小型字置于各段右上方。
- **主线总表只放市场级/行业级事实**：单家公司公告、订单/合同、募资、回购、调研纪要、个股估值与个股涨跌禁止进入主线总表，只进重点公司验证模块。
- **三段式传导图**：重大隔夜事件 → 首要定价变量 → 中国市场主线；第一段到第二段严格一对一，第二段到第三段允许多对多（每变量最多连接3条主线）。
- **溯源**：用户可见标识只能是连续数字脚标，底层 `data-refId` 原样保留；禁止显示 `[know]`/`[news]` 等字母标签。
- 事实、机构观点、本报告分析分层标注，不混用；单一机构不得称为共识；同时发生不得自动写成因果。
- 决策时间线（常驻）中，情景切换矩阵与事件研判均标记为**推演**，不得写成既成事实；未来一周大事预览只列已确认/高概率/市场预期事项，未经确认不进主表。
